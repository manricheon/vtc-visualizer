# VTC Visualizer

[English](README.en.md) | **한국어**

CSV/JSON 데이터를 브라우저에서 논문·기술문서 스타일의 인터랙티브 그래프로 그리는 범용 시각화 도구입니다.
토큰 버짓 대비 성능, 속도 대비 성능 같은 벤치마크 비교 그래프를 자유롭게 커스텀할 수 있습니다.
모든 데이터는 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.

> 📊 **어떤 차트를 언제, 어떻게 써야 잘 전달될까?** — 차트 선택 기준과 시나리오별 레시피는 **[시각화 가이드 (GUIDE.md)](GUIDE.md)** 를 참고하세요.

## 빠른 시작

세 가지 방법 중 아무거나:

1. **더블클릭** — `index.html`을 브라우저로 열고 파일을 드래그 앤 드랍 (인터넷 필요: 차트 라이브러리를 CDN에서 로드)
2. **완전 오프라인** — `index-offline.html`을 더블클릭 (인터넷 불필요, 파일 하나만 복사해가면 어디서든 동작)
3. **폴더 자동 로드** — 데이터 폴더를 지정해 서버 실행:

   ```bash
   python visualizer.py .                 # 처음이라면: 동봉된 example.csv로 바로 체험
   python visualizer.py results/          # results/ 안의 *.csv, *.json 자동 로드
   python visualizer.py                   # 빈 상태로 시작
   python visualizer.py results/ --port 8765
   ```

동봉된 `example.csv`를 드래그해서 기능을 먼저 둘러봐도 좋습니다 — 4개 method × 토큰 버짓(500~16k) 스윕 24행(중복 없음)으로,
토큰이 많을수록 정확도는 포화 곡선으로 오르고 지연·비용은 늘어나는 식의 상식적인 추세가 들어 있습니다
(예: X=tokens, Y=accuracy, 그룹=method — 필터 없이 바로 깔끔한 곡선이 나옵니다).

## 데이터 입력 방법

- CSV/JSON 파일 **드래그 앤 드랍** (여러 개 동시 가능)
- **파일 열기… / 폴더 열기…** 버튼
- **직접 입력…** 버튼 → CSV/JSON 텍스트 붙여넣기
- `visualizer.py`로 실행한 경우 지정 폴더의 파일 자동 로드

파일을 계속 추가하면 데이터가 누적 병합됩니다. 같은 파일명을 다시 넣으면 교체됩니다.

## 데이터 포맷 (입력 계약)

- **CSV**: 첫 줄이 헤더, 이후 한 행 = 한 측정점. (TSV도 지원)
- **JSON**: 객체 배열 `[{"method": "ours", "tokens": 4000, "score": 0.744}, …]`
- **필수 컬럼은 없습니다.** 숫자 컬럼은 자동으로 축 후보가 되고, 문자열 컬럼은 그룹(색상)·필터 후보가 됩니다.
- 컬럼 이름은 자유이며, 파일마다 컬럼이 달라도 됩니다(합집합으로 병합, 빈 값은 `–`).
- 파일을 2개 이상 로드하면 출처 파일명이 `_source` 컬럼으로 나타나 그룹·필터에 쓸 수 있습니다 (1개일 땐 숨겨짐).

권장 형태 (long-form / tidy — 한 행에 한 측정점):

```csv
method,tokens,latency_s,score,dataset
baseline,1000,1.2,0.612,MMLU
baseline,4000,3.8,0.681,MMLU
ours,1000,1.4,0.641,MMLU
ours,4000,4.1,0.744,MMLU
```

## 주요 기능

| 기능 | 사용법 |
|---|---|
| 차트 추가/복제/삭제 | 상단 `＋ 차트 추가`, 카드의 `복제`/`삭제`(토스트에서 **되돌리기**) — 한 페이지에 여러 그래프 |
| **카드 순서·접기** | 카드 헤더 `↑`·`↓`로 순서 변경, `▾`로 그래프 접기. 확대·설정 패널 상태는 차트 추가나 언어 전환에도 유지 |
| **차트 유형** | 산점도 · 선 · 산점도+선 · 막대 · **히트맵**(2D 격자를 색으로) · **덤벨**(카테고리별 짝 비교) |
| **자동 분석** | 상단 `분석` 버튼 → 컬럼 프로파일(타입·결측·분위수)과 인사이트를 **데이터 문제 → 해석 주의 → 발견** 순으로. 등급마다 **어떻게 검증하는지** 한 줄 안내가 붙고, 각 항목의 `＋ 차트`(같은 설정의 차트가 이미 있으면 `차트 보기`)로 근거 차트로 이동. 발견에는 그 차트 설정(유형·X·Y·그룹)이 함께 표시돼 차트와 대조하기 쉽습니다. 자명한 중복 컬럼·심슨 역설·교차를 걸러내며, p값 대신 원단위 차이와 조건별 방향 일관성을 보여줌 |
| **그래프 조작** | 드래그=영역 확대 · 휠=줌 · 더블클릭=전체 보기 · 팬은 모드바 십자 화살표 · `보기 초기화` 버튼으로 리셋. 줌 상태는 스타일을 바꿔도 유지됨 |
| 축·스케일 | 설정 → 축: 레이블, linear/log 토글, min/max 범위(**한쪽만 입력해도 됨**), 그리드 |
| 시리즈 스타일 | 설정 → 스타일: 시리즈별 색·**범례 이름 수정**·마커 심볼/크기·**선 종류(실선/파선/점선)·선 굵기**, 폰트 |
| **차트 크기·배치** | 설정 → 스타일 → 차트 크기: 높이 슬라이더 + **전체/절반 폭**(절반이면 두 차트 나란히). 상단 **폭 토글**(기본/넓게/최대)로 페이지 전체 폭 조절 |
| 범례 위치 | 설정 → 스타일 → 범례: 오른쪽 · 위 · **차트 안 사분면(좌상단/우상단/좌하단/우하단)** · 숨김 |
| 필터 복사 | 설정 → 필터 → `이 필터를 다른 차트에도` — 같은 조건을 여러 차트에 한 번에 |
| 필터 | 설정 → 필터: 컬럼 선택 → 카테고리면 **값 체크박스(여러 개 선택 가능** — 예: method에서 baseline·ensemble 두 개만 체크), 숫자면 비교 연산(>, ≥ 등) **또는 "선택" 연산으로 값 다중 선택**. 각 필터는 **제외**(조건 밖 행 제거) 또는 **흐리게**(조건 밖 행을 옅게 배경 처리 = 규칙 기반 강조) 방식 선택 |
| **언어 (KO/EN)** | 우상단 토글 버튼으로 한국어 ↔ English 전환 (선택 저장됨) |
| **다크 모드** | 우상단 🌙/☀️ 버튼으로 라이트↔다크 전환. 처음엔 OS 설정을 따름, 이후 선택 저장. 차트도 테마에 맞게 조정 |
| **베이스라인** | 포인트 **클릭** → 메뉴에서 "베이스라인 추가" → 가로/세로 점선. **여러 개 지정 가능**, 각각 **십자/가로선만/세로선만** 선택(예: Δ지표의 0선은 가로선만), 십자일 때 사분면 음영, 설정 패널에서 개별 삭제 |
| **텍스트 마커** | 포인트 **클릭** → "텍스트 마커 추가" → 화살표 달린 주석. 드래그로 이동, 클릭으로 수정/삭제 |
| **포인트 제외** | 포인트 **클릭** → "이 포인트 제외" → 모든 차트에서 제거. 토스트의 `실행 취소`, 표의 체크박스, `제외 N행 모두 복원` 버튼으로 롤백 |
| **추세선** | 설정 → 고급: 선형·2차 다항·로그·지수·거듭제곱·이동평균 피팅을 시리즈별로 표시 (선 종류·굵기 조절), **오차 밴드(±1σ/±2σ)** 음영 표시 가능 |
| **모양 그룹 (3번째 차원)** | 설정 → 데이터 → 모양 그룹: 색=그룹1, **마커 모양=그룹2** 이중 인코딩. 예: 색=method, 모양=frames → method별 색은 유지하면서 frames별 경향을 모양으로 구분 |
| 텍스트 마커 스타일 | 포인트 레이블 그룹에서 전체 글자 크기/색/배경/화살표 설정, 마커 클릭 팝업에서 개별 색·크기 오버라이드 |
| 선 스무딩 | 설정 → 스타일 → 선 종류: 직선/곡선(spline), 실선/파선/점선 |
| **영역 채우기** | 설정 → 스타일 → 영역 채우기: 선 아래를 시리즈 색의 연한 파스텔톤으로 채움 |
| **바 차트** | 유형 → 막대: **나란히/쌓기**, **세로/가로**, 같은 X의 여러 행 **집계**(평균·합계·중앙값·최소·최대·개수), 평균 집계 시 **오차 막대(±표준편차/±표준오차)**, 막대 끝 **값 표시**, 이름/값순 **정렬**, 불투명도, 숫자 X를 **카테고리로 취급**(등간격) — 설정 → 막대 옵션. 예: X=method, Y=accuracy, 집계=평균 |
| 포인트 레이블 | 설정 → 포인트 레이블: 표시 후 **드래그**로 위치 조정, **클릭**으로 개별 숨김. 중복 값은 하나만 표시되고 겹침은 자동 회피 |
| Pareto frontier | 설정 → 고급: 방향(예: X작을수록·Y클수록 좋음) 선택 |
| **작은 다중 차트(facet)** | 설정 → 데이터 → 분할: 컬럼 값마다 작은 차트로 나눠 격자 배치 (복제+필터 없이 small multiples) |
| **계산 컬럼** | 데이터 입력 아래 "계산 컬럼": 기존 컬럼으로 새 컬럼 계산 — 이항 연산(A−B, A/B 등) 또는 **기준 대비 델타·유지율**(예: dense 대비). 원본 파일 불변, 축·필터로 바로 사용 |
| **연속 색상** | 설정 → 데이터 → 연속 색상: 숫자 컬럼 값을 색 그라데이션(컬러바)으로 — 그룹 색과 상호배타, 산점/선 전용 |
| **점 집계·오차막대** | 설정 → 고급 → 점 집계: 같은 X의 여러 점(예: seed 반복)을 평균/중앙값 등으로 요약 + **오차막대(±σ/SE)·오차 밴드** |
| **강조/흐리게** | 포인트 **클릭** → "흐리게(강조 안 함)" → 제외하지 않고 옅은 회색 배경으로 물러남(focus+context). 강조할 포인트·라인만 살림. 토스트·표에서 복원 |
| 내보내기 | 카드의 `PNG`(3배 해상도) / `SVG` 버튼, 상단 `모든 차트 PNG`(전체 한 장), 표의 `CSV 내보내기`(현재 필터된 데이터) |
| 원본 데이터 | 하단 표: 검색, 컬럼 클릭 정렬, 데이터셋별 삭제, **행 앞 체크박스 해제로 그래프에서 제외** |
| 세션 | 자동 저장(localStorage) + `세션 내보내기/가져오기`(JSON 파일)로 공유 가능 |
| **차트 프리셋** | 카드의 `프리셋` 버튼: 현재 차트 **설정만**(데이터 제외) 이름 붙여 저장 → 같은 컬럼 이름의 새 데이터에 클릭 한 번으로 재적용. JSON `내보내기/가져오기`로 팀 공유 |

### 팁: 어떤 차트를 언제?

차트 선택 기준(추세=선, 크기 비교=막대, 트레이드오프=산점도), 시나리오별 설정 레시피(평균+오차 막대, 스택,
랭킹, Pareto…), 세 번째 차원 보기, 발표용 마무리 팁은 **[시각화 가이드 (GUIDE.md)](GUIDE.md)** 에 정리되어 있습니다.

## 내 데이터를 이 포맷으로 변환하기 (에이전트 요청문)

자기 로그/실험 결과의 포맷이 무엇이든, 아래 요청문을 Claude 등 아무 LLM 에이전트에 복사해서 붙여넣고
자신의 데이터 파일(또는 경로)을 함께 주면 됩니다:

```text
아래 "입력 계약"에 맞는 CSV 또는 JSON 파일로 내 데이터를 변환해줘.

[입력 계약 — VTC Visualizer]
1. CSV(첫 줄 헤더) 또는 JSON 객체 배열. 인코딩 UTF-8.
2. long-form(tidy) 형태: 한 행 = 한 측정점. 반복 측정이면 행을 반복한다.
   (예: method별 × token budget별 점수라면 method,tokens,score 3컬럼으로 행을 나열)
3. 필수 컬럼은 없다. 다만 다음을 지키면 좋다:
   - 비교 대상(방법/모델/설정 이름)은 문자열 컬럼 하나로 (예: method) → 그래프의 색상 그룹이 된다.
   - 축으로 쓸 값(토큰 수, 시간, 점수 등)은 각각 숫자 컬럼으로. 단위는 컬럼명에 명시 (예: latency_s, cost_usd).
   - 조건 구분(데이터셋, GPU 종류 등)도 각각 별도 컬럼으로 → 필터로 쓸 수 있다.
4. 숫자 컬럼에는 숫자만 넣는다 (단위 문자열 금지, 천단위 콤마 금지, 결측은 빈 값).
5. 컬럼명은 영문 소문자+언더스코어 권장. "_source"라는 이름은 예약되어 있으니 쓰지 말 것.

변환 결과는 *.csv 또는 *.json 파일로 저장해줘. 변환 규칙이 애매한 부분은 나에게 물어봐줘.
```

변환이 자주 필요하면 위 계약에 맞는 자기만의 변환 스크립트를 만들어 쓰는 것도 좋습니다.

## 요구 사항

- 브라우저 (Chrome/Edge/Safari/Firefox 최신)
- `visualizer.py` 사용 시 Python 3.8+ (표준 라이브러리만 사용, 별도 설치 불필요)

## 변경 이력 (Changelog)

버전은 화면 우상단 제목 옆·하단에 표시되며 git 태그(`v0.x`)와 일치합니다.

### v0.12 — 사용성
- **상태 보존**: 차트를 추가하거나 언어를 바꿔도 **확대(줌)와 설정 패널 접힘 상태가 유지**됩니다. 이전에는 모든 카드를 다시 그려 전부 초기화됐습니다.
- **차트 삭제 되돌리기**: 삭제 후 토스트의 `실행 취소`로 축·색·베이스라인까지 그대로 복원됩니다.
- **카드 순서·접기**: 카드 헤더의 `↑`·`↓`로 순서 변경, `▾`로 그래프만 접어 목록처럼 훑기.
- **필터를 다른 차트에도**: 설정 → 필터의 `이 필터를 다른 차트에도` 버튼으로 한 번에 복사(전체 적용 포함).
- **예시 데이터 버튼**: 데이터가 없을 때 `예시 데이터 불러오기` 한 번으로 바로 체험 — 파일을 더블클릭해 연 경우에도 동작합니다.
- 키보드·접근성: `ESC`로 모달·팝오버 닫기, 붙여넣기 창 자동 포커스, 포커스 표시, 아이콘 버튼 설명, 토스트 스크린리더 알림.

### v0.11.1 — 분석 정합성 수정
- 표에서 행을 제외하거나 되돌리면 **분석 결과가 즉시 낡음으로 표시**됩니다(이전에는 제외 전 기준 인사이트가 그대로 남았습니다).
- `visualizer.py`로 폴더를 열었을 때 **같은 이름의 파일이 갱신되면 최신 내용으로 다시 읽습니다**(이전에는 건너뛰어 지난 데이터가 남았습니다).
- 자동 저장이 용량 한계로 실패하면 조용히 넘어가지 않고 알려줍니다.
- 데이터셋이 1개로 줄면 `_source`를 참조하던 축·그룹·필터 설정을 정리합니다.
- 분석: **설계값(조건)이 2개 이상이면 그 조합 단위로 짝을 맞춥니다**(이전에는 첫 번째 조건만 사용). 1:1로 대응하는 설계값은 대표 하나로 접고, 그룹 후보 상한을 24로 올려 모델 20종 비교 같은 경우도 다룹니다.
- 분석 패널에 **검사 범위 한 줄**(그룹 후보·설계값·제외된 컬럼과 이유)이 표시돼, 발견이 없을 때 그 이유를 알 수 있습니다.

### v0.11 — 자동 분석 패널
- 상단 **`분석` 버튼**: 컬럼 프로파일(종류·결측·고유값·최소/중앙/최대/평균/표준편차) + 자동 인사이트 + 프로파일 CSV 내보내기.
- 인사이트는 **데이터(무결성) → 주의(교란) → 발견** 3단계: 상수·빈 컬럼, 숫자에 섞인 문자, 중복 행, 그룹 편향 결측, 측정 안 한 조합 /
  심슨 역설(합치면 뒤집히는 관계)·교차(조건에 따라 우열이 바뀜) / 상관·그룹 차이·포화 지점·이상치.
- **거짓 발견 방지가 핵심**: 정의상 같은 컬럼(예: cost=latency×5e-4)은 대표 하나로 접고, 설계 노브끼리의 상관은 스캔하지 않으며,
  합친 상관이 그룹별과 어긋나면 수치 대신 경고를 냅니다. 이상치는 반복 셀 안 또는 국소 추세 잔차에서 MAD로만 판정하고 자동 제외하지 않습니다.
- **p값·"유의" 표현을 쓰지 않습니다** — 원단위 차이 + 조건별 방향 일관성(예: 6개 중 6개 동일 방향) + **부트스트랩 구간(95%)**으로 신뢰도를 표시. 리샘플링 단위는 행이 아니라 **측정 조건(블록)**이며(벤치마크 행은 서로 독립이 아님), 결정적 난수를 써서 같은 데이터면 항상 같은 구간이 나옵니다. 구간이 0을 포함하면 발견으로 내보내지 않습니다.
- 결과는 세션에 저장하지 않고 데이터가 바뀌면 버립니다. 인사이트 문장은 KO/EN 모두 지원.

### v0.10 — 히트맵·덤벨 차트
- **히트맵**: X·Y 두 이산 축의 격자를 색 값으로 (예: X=frames, Y=gazing_ratio, 색=accuracy). 2D 스윕을 한 장으로.
- **덤벨(짝 비교)**: 카테고리마다 두 조건(예: pretrained/tuned)을 점+연결선으로 — 차이를 직관적으로.

### v0.9 — 페이지 폭
- 상단 **폭 토글**(기본 1280px / 넓게 1660px / 최대=화면 꽉 채움). 넓은 모니터에서 좌우 여백을 줄여 차트를 더 크게. 선택 저장.

### v0.8 — 다크 모드
- **라이트/다크 테마** 토글(우상단 🌙/☀️). 첫 실행은 OS 설정을 따르고, 토글하면 선택이 저장됩니다. 차트 서피스·축·팔레트도 다크에 맞게 조정(단순 반전 아님).

### v0.7 — 차트 크기·배치
- **차트별 높이 슬라이더**(280~820px)와 **전체/절반 폭** 선택. 절반 폭으로 두면 두 차트가 나란히 놓여 미니 대시보드처럼 배치됩니다.

### v0.6.1 — 버그 수정
- 계산 컬럼을 추가/삭제하면 **열려 있던 차트 설정의 축·그룹 드롭다운에 즉시 반영**되도록 수정(이전엔 패널을 다시 열어야 보였음).

### v0.6 — 흐리게 필터
- **필터에 "흐리게" 방식** 추가: 조건 밖 행을 제거하는 대신 옅게 배경 처리 → 규칙 한 줄로 강조(focus+context). 클릭으로 하나씩 흐리게 하던 걸 조건으로 자동화.

### v0.5 — 다중 차트·계산 컬럼
- **작은 다중 차트(facet)**: 컬럼 값별로 격자 분할 — 복제+필터 반복 없이 small multiples.
- **계산 컬럼**: 도구 안에서 이항 연산·기준 대비 델타/유지율 파생 컬럼 생성 (입력 파일 불변, 세션 저장).

### v0.4 — 분석·보고 기능
- **연속 색상**: 숫자 컬럼을 색 그라데이션(컬러바)으로.
- **점 집계·오차막대·오차 밴드**: 같은 X의 반복 측정을 평균 등으로 요약(선/산점도).
- **강조/흐리게(focus+context)**: 포인트를 제외하지 않고 옅게 물러나게 해 핵심만 강조.
- **내보내기**: 모든 차트를 한 장 PNG로, 현재 필터된 데이터를 CSV로.

### v0.3 — 범례 개선
- 범례를 차트 안 **사분면**(좌상단/우상단/좌하단/우하단) 배치.
- **범례 이름 직접 수정**(표시명만, 내부 식별자 불변).

### v0.2 — 막대 차트·가이드·프리셋
- **바 차트**: 그룹/스택, 가로 방향, 집계(평균 등), 오차막대, 값 표시, 정렬.
- **시각화 가이드**(GUIDE.md/en) + 예시 캡처.
- **차트 프리셋**: 차트 설정만 저장 → 새 데이터에 재적용.
- 베이스라인 방향(십자/가로/세로), 로그축 베이스라인 위치 버그 수정, 숫자 컬럼 다중 선택 필터, 세션 파일 데이터 오인 방지, 버전 배지.

# VTC Visualizer

[English](README.en.md) | **한국어**

CSV/JSON 데이터를 브라우저에서 논문·기술문서 스타일의 인터랙티브 그래프로 그리는 범용 시각화 도구입니다.
토큰 버짓 대비 성능, 속도 대비 성능 같은 벤치마크 비교 그래프를 자유롭게 커스텀할 수 있습니다.
모든 데이터는 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.

> 📊 **어떤 차트를 언제, 어떻게 써야 잘 전달될까?** — 차트 선택 기준과 시나리오별 레시피는 **[시각화 가이드 (GUIDE.md)](GUIDE.md)** 를 참고하세요.

## 빠른 시작

세 가지 방법 중 아무거나:

1. **더블클릭** — `index.html`을 브라우저로 열고 파일을 드래그 앤 드랍 (인터넷 필요: 차트 라이브러리를 CDN에서 로드)
2. **완전 오프라인** — `index-offline.html`을 더블클릭 (인터넷 불필요, 파일 하나만 복사해가면 어디서든 동작)
3. **폴더 자동 로드** — 데이터 폴더를 지정해 서버 실행:

   ```bash
   python visualizer.py .                 # 처음이라면: 동봉된 example.csv로 바로 체험
   python visualizer.py results/          # results/ 안의 *.csv, *.json 자동 로드
   python visualizer.py                   # 빈 상태로 시작
   python visualizer.py results/ --port 8765
   python visualizer.py results/ --host 0.0.0.0   # 같은 네트워크의 다른 기기에서 열기(폴더가 공개됩니다)
   ```

   폴더의 파일이 바뀌면 화면의 `폴더 감시`를 켜 두세요 — 새 결과가 자동으로 들어옵니다.

   하위 폴더의 파일까지 함께 읽습니다(목록에는 `sub/run1.csv`처럼 상대 경로로 나옵니다).
   숨김 폴더(`.git`·`.venv` 등)와 폴더 밖을 가리키는 심볼릭 링크는 건너뛰고, 목록은 500개까지입니다.

동봉된 `example.csv`를 드래그해서 기능을 먼저 둘러봐도 좋습니다 — 4개 method × 토큰 버짓(500~16k) 스윕 24행(중복 없음)으로,
토큰이 많을수록 정확도는 포화 곡선으로 오르고 지연·비용은 늘어나는 식의 상식적인 추세가 들어 있습니다
(예: X=tokens, Y=accuracy, 그룹=method — 필터 없이 바로 깔끔한 곡선이 나옵니다).

## 데이터 입력 방법

- CSV/JSON 파일 **드래그 앤 드랍** (여러 개 동시 가능)
- **파일 열기… / 폴더 열기…** 버튼
- **직접 입력…** 버튼 → CSV/JSON 텍스트 붙여넣기
- `visualizer.py`로 실행한 경우 지정 폴더의 파일 자동 로드

파일을 계속 추가하면 데이터가 누적 병합됩니다. 같은 파일명을 다시 넣으면 교체됩니다.

## 데이터 포맷 (입력 계약)

- **CSV**: 첫 줄이 헤더, 이후 한 행 = 한 측정점. (TSV도 지원)
- **JSON**: 객체 배열 `[{"method": "ours", "tokens": 4000, "score": 0.744}, …]`
- **필수 컬럼은 없습니다.** 숫자 컬럼은 자동으로 축 후보가 되고, 문자열 컬럼은 그룹(색상)·필터 후보가 됩니다.
- 컬럼 이름은 자유이며, 파일마다 컬럼이 달라도 됩니다(합집합으로 병합, 빈 값은 `–`).
- 파일을 2개 이상 로드하면 출처 파일명이 `_source` 컬럼으로 나타나 그룹·필터에 쓸 수 있습니다 (1개일 땐 숨겨짐).

권장 형태 (long-form / tidy — 한 행에 한 측정점):

```csv
method,tokens,latency_s,score,dataset
baseline,1000,1.2,0.612,MMLU
baseline,4000,3.8,0.681,MMLU
ours,1000,1.4,0.641,MMLU
ours,4000,4.1,0.744,MMLU
```

## 주요 기능

| 기능 | 사용법 |
|---|---|
| 차트 추가/복제/삭제 | 상단 `＋ 차트 추가`, 카드의 `복제`/`삭제`(토스트에서 **되돌리기**) — 한 페이지에 여러 그래프 |
| **카드 순서·접기** | 카드 헤더 `↑`·`↓`로 순서 변경, `▾`로 그래프 접기. 확대·설정 패널 상태는 차트 추가나 언어 전환에도 유지 |
| **차트 유형** | 산점도 · 선 · 산점도+선 · 막대 · **히트맵**(2D 격자를 색으로) · **덤벨**(카테고리별 짝 비교) · **히스토그램** · **박스플롯**(분포) · **바이올린**(분포 모양까지) · **누적분포 ECDF**(몇 %가 이 값 이하인가) · **축 끊기**(값이 두 무리로 갈릴 때 사이를 접어 둘 다 읽히게 — 축 값은 진짜 값 그대로) |
| **차트 색 팔레트** | 상단 선택: 기본 · Carbon · Okabe-Ito · 잉크 톤 — 전부 색약 안전 검증을 통과한 조합, 라이트/다크 각각 별도 단계 |
| **보조 Y축** | 설정 → 데이터 → 보조 Y축: 스케일이 다른 두 지표를 한 차트에 (오른쪽 축, 점선·× 마커) |
| **축 눈금 표기** | 설정 → 축 → X/Y 눈금 표기: 자동 · 퍼센트 · 천단위 · 지수 · 소수 자릿수(0~3) |
| **설정 검색** | 설정 패널 위 검색창에 옵션 이름을 입력하면 해당 항목만 표시. **감춘 고급 설정도 검색으로 찾습니다** |
| **간단 ⇄ 전부** | 설정 패널 위 `간단히` 체크(기본 켜짐): 자주 쓰는 16줄만 보이고 나머지는 접힙니다(전부 46줄). **값이 들어 있는 설정은 감추지 않고**, 패널 맨 아래 `고급 설정 N줄 더 보기`로 언제든 폅니다 |
| **레시피 칩** | 데이터를 넣으면 데이터 카드에 `이렇게 그려보기:` 줄이 뜹니다 — 지금 컬럼으로 **실제 그려지는 레시피만** 나오고, 누르면 첫 차트에 적용됩니다(카드는 늘지 않습니다) |
| **자동 분석** | 상단 `분석` 버튼 → 컬럼 프로파일(타입·결측·분위수)과 인사이트를 **데이터 문제 → 해석 주의 → 발견** 순으로. 등급마다 **어떻게 검증하는지** 한 줄 안내가 붙고, 각 항목의 `＋ 차트`(같은 설정의 차트가 이미 있으면 `차트 보기`)로 근거 차트로 이동. 발견에는 그 차트 설정(유형·X·Y·그룹)이 함께 표시돼 차트와 대조하기 쉽습니다. 자명한 중복 컬럼·심슨 역설·교차를 걸러내며, p값 대신 원단위 차이와 조건별 방향 일관성을 보여줌 |
| **그래프 조작** | 드래그=영역 확대 · 휠=줌 · 더블클릭=전체 보기 · 팬은 모드바 십자 화살표 · `보기 초기화` 버튼으로 리셋. 줌 상태는 스타일을 바꿔도 유지됨 |
| 축·스케일 | 설정 → 축: 레이블, linear/log 토글, min/max 범위(**한쪽만 입력해도 됨**), 그리드 |
| 시리즈 스타일 | 설정 → 스타일: 시리즈별 색·**범례 이름 수정**·마커 심볼/크기·**선 종류(실선/파선/점선)·선 굵기**·**표시 모드(점만/선만/점+선)**, 폰트. **순서 바꾸기**(↑↓ — 범례·그리는 순서만 바뀌고 **색은 그 시리즈를 따라갑니다**) |
| **카드 접기** | 헤더 `▾`로 카드를 헤더 한 줄로 접습니다(요약은 남음). 접힘은 세션에 저장되고, 헤더 `모두 접기`로 한 번에 |
| **카드 요약** | 설정을 접으면 헤더에 `유형 · X × Y · 그룹 · 필터 수 · 데이터`가 한 줄로 나옵니다 |
| **차트 크기·배치** | 설정 → 스타일 → 차트 크기: 높이 슬라이더 + **전체/절반 폭**(절반이면 두 차트 나란히). 상단 **폭 토글**(기본/넓게/최대)로 페이지 전체 폭 조절. **설정 패널 폭**(좁게/기본/넓게/아주 넓게)은 패널 위에서 고르며 모든 차트에 함께 적용. 패널 높이는 화면을 따르고 `하나씩` 체크로 한 묶음만 펼침(시리즈 목록은 접힌 채 시작) |
| 범례 위치 | 설정 → 스타일 → 범례: 오른쪽 · 위 · **차트 안 사분면(좌상단/우상단/좌하단/우하단)** · 숨김 |
| 필터 복사 | 설정 → 필터 → `이 필터를 다른 차트에도` — 같은 조건을 여러 차트에 한 번에 |
| 필터 | 설정 → 필터: 컬럼 선택 → 카테고리면 **값 체크박스(여러 개 선택 가능** — 예: method에서 baseline·ensemble 두 개만 체크), 숫자면 비교 연산(>, ≥ 등) **또는 "선택" 연산으로 값 다중 선택**. 각 필터는 **제외**(조건 밖 행 제거) 또는 **흐리게**(조건 밖 행을 옅게 배경 처리 = 규칙 기반 강조) 방식 선택 |
| **언어 (KO/EN)** | 우상단 토글 버튼으로 한국어 ↔ English 전환 (선택 저장됨) |
| **다크 모드** | 우상단 🌙/☀️ 버튼으로 라이트↔다크 전환. 처음엔 OS 설정을 따름, 이후 선택 저장. 차트도 테마에 맞게 조정 |
| **베이스라인** | 포인트 **클릭** → 메뉴에서 "베이스라인 추가" → 가로/세로 점선. **여러 개 지정 가능**, 각각 **십자/가로선만/세로선만** 선택(예: Δ지표의 0선은 가로선만), 십자일 때 사분면 음영, 설정 패널에서 개별 삭제, **그 점(행)에 묶여** 데이터를 갱신해도 새 값을 따라갑니다(설정에서 값으로 넣은 기준선은 그 값에 고정). 기준 점이 사라지면 엉뚱한 자리에 그리지 않고 ⚠로 알린 뒤 `다시 지정`할 수 있습니다 |
| **최적점 표시** | 설정 → 포인트 레이블 → 최적점 표시: Y가 가장 큰/작은 점에 라벨을 자동으로 붙입니다(전체 하나 또는 시리즈마다). **그릴 때마다 지금 데이터에서 다시 고르므로** 데이터가 바뀌면 따라 움직입니다 — 손으로 놓는 텍스트 마커와 다른 점입니다 |
| **텍스트 마커** | 포인트 **클릭** → "텍스트 마커 추가" → 화살표 달린 주석. 드래그로 이동, 클릭으로 수정/삭제. 마커는 **그 점(행)에 묶여서** 데이터를 갱신해도 새 값을 따라갑니다. 설정 → 포인트 레이블의 `＋ 텍스트 마커`로 **행을 골라서도** 만들 수 있습니다(마우스 없이) |
| **고정 메모** | 설정 → 포인트 레이블 → `＋ 고정 메모`: 데이터 점과 무관하게 차트 한구석에 붙는 메모(`n=24 · 2026-07 측정` 등). 데이터·축이 바뀌어도 자리를 지키며 드래그로 옮깁니다 |
| **기준 잃은 마커 알림** | 앵커 행이 사라지거나(필터·제외·삭제) 축 컬럼이 바뀌면 **엉뚱한 자리에 그리지 않고 숨긴 뒤** 알립니다. 설정 목록에 ⚠와 사유가 남고 `다시 지정`으로 다른 점에 붙일 수 있습니다 |
| **포인트 제외** | 포인트 **클릭** → "이 포인트 제외" → 모든 차트에서 제거. 토스트의 `실행 취소`, 표의 체크박스, `제외 N행 모두 복원` 버튼으로 롤백 |
| **추세선** | 설정 → 고급: 선형·2차 다항·로그·지수·거듭제곱·이동평균 피팅을 시리즈별로 표시 (선 종류·굵기 조절), **오차 밴드(±1σ/±2σ)** 음영 표시 가능 |
| **모양 그룹 (3번째 차원)** | 설정 → 데이터 → 모양 그룹: 색=그룹1, **마커 모양=그룹2** 이중 인코딩. 예: 색=method, 모양=frames → method별 색은 유지하면서 frames별 경향을 모양으로 구분 |
| 텍스트 마커 스타일 | 포인트 레이블 그룹에서 전체 글자 크기/색/배경/화살표 설정, 마커 클릭 팝업에서 개별 색·크기 오버라이드 |
| 선 스무딩 | 설정 → 스타일 → 선 종류: 직선/곡선(spline), 실선/파선/점선 |
| **영역 채우기** | 설정 → 스타일 → 영역 채우기: 선 아래를 시리즈 색의 연한 파스텔톤으로 채움 |
| **바 차트** | 유형 → 막대: **나란히/쌓기**, **세로/가로**, 같은 X의 여러 행 **집계**(평균·합계·중앙값·최소·최대·개수), 평균 집계 시 **오차 막대(±표준편차/±표준오차)**, 막대 끝 **값 표시**, 이름/값순 **정렬**, 불투명도, 숫자 X를 **카테고리로 취급**(등간격) — 설정 → 막대 옵션. 예: X=method, Y=accuracy, 집계=평균 |
| 포인트 레이블 | 설정 → 포인트 레이블: 표시 후 **드래그**로 위치 조정, **클릭**으로 개별 숨김. 중복 값은 하나만 표시되고 겹침은 자동 회피 |
| Pareto frontier | 설정 → 고급: 방향(예: X작을수록·Y클수록 좋음) 선택 |
| **작은 다중 차트(facet)** | 설정 → 데이터 → 분할: 컬럼 값마다 작은 차트로 나눠 격자 배치 (복제+필터 없이 small multiples) |
| **차트별 데이터** | 파일을 2개 이상 넣으면 각 차트 설정 맨 위에 `데이터` 드롭다운이 생깁니다. 파일을 고르면 **그 파일 행만** 그리고, 축·그룹·필터 목록도 **그 파일에 있는 컬럼만** 보여줍니다. 차트마다 다른 파일을 지정할 수 있어 서로 다른 데이터셋을 나란히 놓고 볼 수 있습니다 (`(전체)`로 되돌리면 다시 합쳐서 봅니다) |
| **라벨 조합 컬럼** | 계산 컬럼 → 종류 `라벨 조합`: 값을 계산하지 않고 **여러 컬럼의 값을 이어 붙여 문자열 컬럼**을 만듭니다. 조각마다 앞뒤 텍스트를, 사이에는 구분자를 붙일 수 있습니다 (예: `method` + `frames` → `baseline · 8frm`). 만들어진 컬럼은 그룹·분할·필터·막대 X축으로 바로 쓰입니다 |
| **계산 컬럼** | 데이터 입력 아래 "계산 컬럼": 기존 컬럼으로 새 컬럼 계산 — 이항 연산(A−B, A/B 등) 또는 **기준 대비 델타·유지율**(예: dense 대비). 원본 파일 불변, 축·필터로 바로 사용 |
| **예시 데이터** | `예시 데이터 불러오기`로 기본 24행을, `예시 더`로 짝 데이터 5개(메타·가로 CSV·표준편차·seed 반복·자릿수가 다른 두 백엔드)를 넣습니다 — 가이드 레시피 ⑮⑯⑰를 그대로 따라 할 수 있습니다 |
| **가로 → 세로 녹이기** | 데이터 칩의 `⇲` 버튼: 컬럼이 가로로 펼쳐진 파일(`baseline, ours, ablation`)을 **한 행 = 한 측정점**으로 바꿔 새 데이터셋으로 만듭니다. 원본은 그대로 두고, 녹인 이름 컬럼은 바로 그룹·분할·필터로 쓰입니다 |
| **폴더 감시** | `visualizer.py`로 실행했을 때 나타나는 `폴더 감시` 체크: 폴더의 파일이 바뀌면 **자동으로 다시 읽습니다**. 실험을 돌리는 중에 열어 두세요 — 제외·흐리게 표시는 그대로 유지되고, 파일이 잠깐 사라져도 화면에서 지우지 않습니다 |
| **공유용 HTML 한 장** | `내보내기 ▾` → `공유용 HTML 한 장`: 지금 데이터와 모든 차트 설정을 **한 파일에 박아** 저장합니다. 받는 사람은 더블클릭만 하면 됩니다(도구도 세션 파일도 따로 필요 없음). `index-offline.html`에서 만들면 인터넷 없이도 열립니다 |
| **파일 간 결합** | 계산 컬럼 → 종류 `다른 파일에서 가져오기`: 다른 파일의 값을 **키로 찾아 컬럼 하나로** 붙입니다 (예: `runs.csv`에 `models.csv`의 `params_b`). 키 후보는 **양쪽에 다 있는 컬럼**만 나오고, 고르는 즉시 **몇 행이 짝을 찾는지** 미리 알려 줍니다. 짝이 여럿이면 첫 값/평균/합/최소/최대/개수로 접습니다. **행은 절대 늘어나지 않습니다** |
| **연속 색상** | 설정 → 데이터 → 연속 색상: 숫자 컬럼 값을 색 그라데이션(컬러바)으로 — 그룹 색과 상호배타, 산점/선 전용 |
| **점 집계·오차막대** | 설정 → 고급 → 점 집계: 같은 X의 여러 점(예: seed 반복)을 평균/중앙값 등으로 요약 + **오차막대(±σ/SE)·오차 밴드** |
| **강조/흐리게** | 포인트 **클릭** → "흐리게(강조 안 함)" → 제외하지 않고 옅은 회색 배경으로 물러남(focus+context). 강조할 포인트·라인만 살림. 토스트·표에서 복원. 스타일 → `흐리게 색`으로 **회색 대신 시리즈 색을 옅게** 남길 수도 있음 |
| **내보내기 규격** | 설정 → 내보내기 규격: **논문 1단(85mm)·2단(170mm)·슬라이드** 프리셋 또는 mm/inch로 직접, dpi 지정. 안내에 **저장될 픽셀과 본문 글자의 pt**가 나옵니다 (dpi를 올려도 글자의 물리 크기는 그대로 — 키우려면 글자 크기를 올립니다). 리포트에 들어가는 그림도 이 규격을 따릅니다 |
| **오차 컬럼** | 설정 → 데이터 → 오차 컬럼: `score_std`처럼 **± 값이 이미 컬럼으로 있을 때** 그대로 오차막대로 그립니다. 집계 중에는 무시합니다(그때는 집계 오차막대가 그 자리) |
| **구간 음영** | 설정 → 베이스라인 → `＋ 구간`: 한 축의 **범위**를 띠로 칠하고 이름을 붙입니다(권장 대역, 메모리 초과 구간 등). 베이스라인이 "선 하나"라면 이건 "이 범위" |
| **누적 영역** | 설정 → 스타일 → 영역 채우기 → `쌓기`: 시리즈를 위로 쌓아 합계와 구성비를 함께 봅니다(선이 있는 유형 전용) |
| **차트를 표로** | 카드의 `표` 버튼: 그 차트가 쓰는 컬럼만, 그 차트의 필터를 적용한 행으로 표를 함께 보여줍니다. 그래프를 읽을 수 없을 때의 유일한 길이고, 정확한 값을 확인할 때도 씁니다 |
| **이미지 주석** | `내보내기 ▾` → `이미지 주석…`: 별도 페이지(`annotate.html`)에서 캡처에 **텍스트·화살표·사각형·가리기**를 얹고 PNG로 저장합니다. 스크린샷은 붙여넣기(⌘/Ctrl+V)로 바로 넣습니다. 이미지는 브라우저 밖으로 나가지 않습니다. **별도 파일이므로 `index.html`과 같은 폴더에 두어야 합니다** |
| 내보내기 | 카드의 `PNG`(3배 해상도) / `SVG` 버튼, 상단 `내보내기 ▾` 메뉴의 `모든 차트 PNG`(전체 한 장), 표의 `CSV 내보내기`(현재 필터된 데이터) |
| **렌더링 속도** | 설정 → 스타일 → 렌더링: `자동`(5천 점 이상이면 WebGL) / `고품질 (SVG)` / `고속 (WebGL)`. WebGL로 그려도 SVG 내보내기는 벡터로 저장 |
| 원본 데이터 | 하단 표: 검색, 컬럼 클릭 정렬(**헤더에서 Enter로도**), 데이터셋별 삭제, **행 앞 체크박스 해제로 그래프에서 제외**, **`흐리게` 열로 강조 제외**. 숫자 컬럼은 자릿수를 맞춰 우측 정렬 |
| **키보드·접근성** | 마우스 없이도 씁니다: 첫 Tab에 **차트로 건너뛰기** 링크, 설정 컨트롤마다 이름 연결, 팝오버·모달은 열면 포커스가 안으로·Escape면 열었던 버튼으로 복귀(모달은 Tab이 밖으로 새지 않음), 표 헤더는 Enter로 정렬. 포인트 클릭 전용이던 **흐리게는 표에서**, **베이스라인은 설정 패널에서 값으로** 추가합니다 |
| **컬럼 숨김** | 표의 `컬럼 n/m` 버튼: 체크를 끄면 표·축 선택·필터·자동 분석에서 한꺼번에 빠집니다. **데이터는 그대로**이고 이미 그린 차트도 유지됩니다(참조를 끊지 않음). 컬럼이 20~40개인 로그에서 필요한 것만 남길 때 — `쓰는 것만`으로 차트가 참조하는 컬럼만 남기고 `모두 표시`로 되돌립니다 |
| 세션 | 자동 저장(localStorage) + `내보내기 ▾` 메뉴의 `세션 내보내기/가져오기`(JSON 파일)로 공유 가능 |
| **기본 프리셋** | 카드의 `프리셋` 버튼 상단: 평균 비교(막대)·스윕 추세(선)·트레이드오프(Pareto)·두 조건 격자(히트맵)·값 분포(박스). **컬럼 이름을 가정하지 않고** 지금 데이터에서 역할(범주·스윕 노브·점수·비용)을 찾아 맞춥니다. 종류는 **값의 분포**로 가리므로 이름이 도메인 약어여도 동작하고, 식별자·시드 컬럼은 축으로 쓰지 않습니다. 맞는 컬럼이 없는 항목은 목록에 뜨지 않습니다 |
| **차트 프리셋** | 카드의 `프리셋` 버튼: 현재 차트 **설정만**(데이터 제외) 이름 붙여 저장 → 같은 컬럼 이름의 새 데이터에 클릭 한 번으로 재적용. JSON `내보내기/가져오기`로 팀 공유 |

### 팁: 어떤 차트를 언제?

차트 선택 기준(추세=선, 크기 비교=막대, 트레이드오프=산점도), 시나리오별 설정 레시피(평균+오차 막대, 스택,
랭킹, Pareto…), 세 번째 차원 보기, 발표용 마무리 팁은 **[시각화 가이드 (GUIDE.md)](GUIDE.md)** 에 정리되어 있습니다.

## 내 데이터를 이 포맷으로 변환하기 (에이전트 요청문)

자기 로그/실험 결과의 포맷이 무엇이든, 아래 요청문을 Claude 등 아무 LLM 에이전트에 복사해서 붙여넣고
자신의 데이터 파일(또는 경로)을 함께 주면 됩니다:

```text
아래 "입력 계약"에 맞는 CSV 또는 JSON 파일로 내 데이터를 변환해줘.

[입력 계약 — VTC Visualizer]
1. CSV(첫 줄 헤더) 또는 JSON 객체 배열. 인코딩 UTF-8.
2. long-form(tidy) 형태: 한 행 = 한 측정점. 반복 측정이면 행을 반복한다.
   (예: method별 × token budget별 점수라면 method,tokens,score 3컬럼으로 행을 나열)
3. 필수 컬럼은 없다. 다만 다음을 지키면 좋다:
   - 비교 대상(방법/모델/설정 이름)은 문자열 컬럼 하나로 (예: method) → 그래프의 색상 그룹이 된다.
   - 축으로 쓸 값(토큰 수, 시간, 점수 등)은 각각 숫자 컬럼으로. 단위는 컬럼명에 명시 (예: latency_s, cost_usd).
   - 조건 구분(데이터셋, GPU 종류 등)도 각각 별도 컬럼으로 → 필터로 쓸 수 있다.
4. 숫자 컬럼에는 숫자만 넣는다 (단위 문자열 금지, 천단위 콤마 금지, 결측은 빈 값).
5. 컬럼명은 영문 소문자+언더스코어 권장. "_source"라는 이름은 예약되어 있으니 쓰지 말 것.

변환 결과는 *.csv 또는 *.json 파일로 저장해줘. 변환 규칙이 애매한 부분은 나에게 물어봐줘.
```

변환이 자주 필요하면 위 계약에 맞는 자기만의 변환 스크립트를 만들어 쓰는 것도 좋습니다.

## 알려진 한계 (일부러 그렇게 둔 것)

고칠 수 있지만 값이 안 나온다고 판단해 그대로 둔 것들입니다. 이유를 적어 두는 편이 다음에 같은 판단을 다시 하는 것보다 낫다고 봅니다.

- **분석 실행이 오래 걸립니다** — 연속량 컬럼이 20개인 5만 행에서 약 3초. 눈에 띄는 부분(상관 쌍마다 그룹을 다시 나누는 것)을 미리 계산해 봤더니 **10%밖에 줄지 않았고**(3,177 → 2,865 ms) 대신 미묘한 순서 불변이 생겨 되돌렸습니다. CPU 프로파일상 비용이 한 곳이 아니라 흩어져 있습니다. 버튼을 눌러 기다리는 동작이고, 스캔은 표본을 쓰므로 행이 늘어도 거의 평평합니다.
- **차트를 여러 장 열면 WebGL 컨텍스트 한도에 걸릴 수 있습니다** — 브라우저 제한입니다. 설정 → 스타일 → 렌더링에서 `고품질 (SVG)`로 고정하면 피할 수 있습니다.
- **기본 프리셋은 데이터당 한 벌만 제안합니다** — 연속량이 여럿이어도 점수·비용을 하나씩만 고릅니다. 후보를 여러 개 내놓으면 목록이 금세 길어집니다. 적용한 뒤 축을 바꾸세요.
- **폴더 감시는 4초 주기 폴링입니다** — 로컬 폴더에서는 충분했습니다.
- **파일 간 결합은 정의 하나당 컬럼 하나입니다** — 메타를 넷 붙이려면 정의를 넷 만듭니다. 한 정의가 여러 컬럼을 내면 삭제·이름 충돌 검사·사용처 조회가 전제하는 "정의 1 = 이름 1"이 흔들립니다.

### v0.35 — 파일을 더 넣으면 기준선이 사라지던 것

- **버그 수정**: 데이터 파일을 하나 더 넣으면 클릭으로 만든 **기준선·텍스트 마커가 곧바로 "기준 점을 잃었다"며 사라졌습니다**(`예시 더` 버튼 한 번으로 재현됩니다).
- 행을 알아보는 키 컬럼을 **전체 파일을 합쳐서** 고르고 있었습니다. 파일이 늘면 그 파일에만 있는 컬럼이 나머지 행에서 빈 값이라 "값이 몇 개뿐인 조건 컬럼"으로 보였고, `f1`·`latency_ms` 같은 **측정값이 행 정체성에 섞여** 저장해 둔 앵커가 전부 어긋났습니다.
- 이제 **파일마다 따로** 판정합니다 — 한 행의 정체성은 그 행이 온 파일의 스키마로 정해지므로 다른 파일이 들고 나도 흔들리지 않습니다. 같은 파일을 갱신할 때 제외·흐리게 표시가 되붙는 것도 같은 이유로 안정됩니다.
- 예전 세션에서 만든 앵커도 계속 찾아갑니다(옛 방식 키를 함께 조회합니다).

### v0.32 — 분포 모양·시리즈 순서·최적점
- **바이올린**과 **누적분포(ECDF)**가 생겼습니다. 박스플롯은 사분위수만 보여줘서 **이봉성이나 꼬리가 사라집니다** — seed 반복 결과를 비교할 때 실제로 문제가 됩니다. ECDF는 "몇 %가 이 값 이하인가"를 그림에서 바로 읽게 합니다(계단선입니다 — 직선으로 이으면 관측되지 않은 값에 확률을 주게 됩니다).
- **시리즈 순서**를 ↑↓로 바꿀 수 있습니다. 지금까지는 데이터 등장 순 그대로라 `baseline`을 맨 앞에 두려면 CSV 행 순서를 고치는 수밖에 없었습니다. **색은 따라오지 않습니다** — 색은 자리가 아니라 그 시리즈의 것입니다.

### v0.25 — 파일 간 결합
- **다른 파일의 값을 키로 찾아 붙일 수 있습니다.** 계산 컬럼에 종류 `다른 파일에서 가져오기`가 생겼습니다 — `runs.csv`(측정)와 `models.csv`(파라미터·가격 같은 메타)를 따로 두고도 한 그림에서 씁니다. 여태 파일 병합은 행을 이어 붙이는 것뿐이라 이런 구성은 다룰 수 없었습니다.

- **버그 수정**: 계산 컬럼이 "같은 행"을 알아보는 기준에 섞여 들어가고 있었습니다. 그래서 계산 컬럼이 있는 상태에서 같은 파일을 다시 넣으면 **손으로 표시한 제외·흐리게가 통째로 사라졌습니다**. 계산 컬럼은 데이터에서 다시 만들어지는 값이므로 이제 기준에서 제외합니다.

- 프런티어 선의 **모양(실선/파선/점선/일점쇄선)과 굵기**를 고를 수 있습니다(고급 → Pareto). 기본은 실선·2입니다.
- `산점도+선` 차트에서는 시리즈 선도 실선이라 프런티어와 헷갈릴 수 있는데, 그럴 때 파선으로 되돌리면 됩니다.
- **색은 열지 않았습니다.** 프런티어는 특정 시리즈의 것이 아니라 전체에 대한 판정이라, 시리즈 색을 주면 그 그룹의 선처럼 읽힙니다. 테마 잉크색으로 고정하고 라이트/다크만 따라갑니다.

### v0.21 — 파레토를 읽을 수 있게
- **프런티어 선이 회색 점선에서 잉크색 실선으로** 바뀌었습니다. 베이스라인(회색 점선)과 톤이 같아 배경으로 묻혔고, 어느 점이 선 위인지도 알 수 없었습니다. 이제 선이 닿는 점이 곧 후보라는 게 보입니다.
- **`지배당한 점 흐리게`** 옵션이 생겼습니다(고급 → Pareto 아래). 켜면 프런티어 위 점만 진하게 남고 나머지는 배경으로 물러납니다. 옅어진 점도 원래 색을 유지해 어느 그룹이었는지는 계속 읽힙니다.
- 범례 견본이 옅은 시리즈는 **프런티어에 오른 점이 하나도 없다**는 뜻입니다 — 전부 지배당한 방법을 한눈에 알 수 있습니다.
- 프런티어는 **그룹과 무관하게 전체 점에서** 계산합니다(예전부터 그랬습니다). 선 위의 점이 곧 "고를 이유가 있는" 설정입니다.

### v0.20.1 — 파레토 재점검
- **점 집계를 켜면 프런티어가 엉뚱한 곳에 그려졌습니다.** 화면의 점은 평균인데 프런티어는 원본 행으로 계산해서, 점선이 어느 점도 지나지 않았습니다. 이제 **화면에 그려진 점**(집계 결과)으로 계산합니다.
- **흐리게 처리한 행이 프런티어를 정하던 것**도 고쳤습니다 — 추세선이 이미 그런 행을 제외하는 것과 같은 이유로, 강조에서 빼 둔 점은 경계를 정하지 않습니다.
- **분할(facet)에서는 그리지 않습니다.** 전체 데이터로 계산한 선이 첫 패널에만 얹혀 다른 패널을 오해하게 만들었습니다(베이스라인·마커·레이블과 같은 처리).
- 범례의 `Pareto frontier`가 한국어에서도 영어로 나왔습니다 — 이제 언어를 따릅니다.
- 프런티어 계산 자체(4방향)는 독립 구현과 대조해 **모두 정확함을 확인**했습니다.

### v0.20 — 필터가 무엇을 하는지 말해 줍니다
- 필터마다 **지금 몇 행이 걸리는지 문장으로** 표시합니다 — `맞는 행 6 / 24 — 나머지 18행은 빠집니다`. 값을 입력하는 동안에도 숫자가 따라옵니다.
- **어느 쪽에 무엇을 할지 직접 고릅니다.** 방식이 네 가지가 됐습니다 — `조건 밖 제거`(기본) · `맞는 것 제거` · `조건 밖 흐리게` · `맞는 것 흐리게`. `method = baseline` + `맞는 것 흐리게`면 baseline만 옅어지고, `조건 밖 흐리게`면 반대로 baseline만 진하게 남습니다. 예전에는 한 방향만 있어서 반대로 이해하기 쉬웠습니다.
- 이름만 봐도 대상이 드러나고, 문장이 실제 행 수로 확인해 줍니다 — 잘못 고르면 숫자가 먼저 이상해집니다.
- 필터 줄이 좁아 무엇을 고르는 칸인지 알기 어려웠던 것도 고쳤습니다 — 컨트롤에 최소 폭을 주고 좁으면 줄로 접힙니다.

### v0.19 — 파일별로 따로 보기
- 파일이 2개 이상이면 차트마다 **`데이터` 드롭다운**으로 그릴 파일을 고릅니다. 그 파일 행만 그리고, **컬럼 목록도 그 파일 것만** 남습니다 — 스키마가 다른 파일을 함께 열어도 없는 컬럼을 잘못 고를 일이 없습니다.
- 차트마다 다르게 지정할 수 있어 **전혀 다른 두 데이터셋을 한 페이지에 나란히** 놓을 수 있습니다. `(전체)`를 고르면 예전처럼 합쳐서 봅니다.
- 데이터셋을 바꿔서 **못 쓰게 된 축·그룹·필터 설정은 비우고** 무엇을 비웠는지 알립니다. 지정한 파일을 지우면 자동으로 `(전체)`로 돌아오면서 같은 정리를 합니다.
- 파일별로 나눠 보는 방법은 원래도 있었습니다(`_source` 컬럼을 분할·그룹·필터에 쓰기). 이번 것은 그 위에 얹은 지름길이라, 여러 파일을 겹쳐 비교하고 싶으면 여전히 분할=`_source`가 좋습니다.

### v0.18 — 조건 조합을 한 컬럼으로
- 계산 컬럼에 **`라벨 조합`** 종류가 생겼습니다. 값을 계산하는 대신 여러 컬럼의 값을 이어 붙여 문자열 컬럼을 만듭니다 — `selector` + `frames` → `sal-v3.1 · 16frm` 같은 식입니다.
- 조각마다 **앞뒤 텍스트**(`16` → `16frm`), 조각 사이에는 **구분자**를 정할 수 있고, 조각은 몇 개든 더할 수 있습니다.
- 결과가 문자열이라 **그룹(색상)·분할·필터·막대 X축**에 바로 쓰입니다. 조건 조합별로 한 줄씩 놓고 비교하는 그림이 클릭 몇 번으로 나옵니다.
- 값이 없는 조각은 건너뛰므로 구분자만 덩그러니 남지 않고, 전부 비어 있으면 값 없음으로 둡니다.

### v0.17.1 — 이름을 몰라도 맞도록
- 기본 프리셋의 역할 판정을 **이름 패턴에서 값의 분포로** 옮겼습니다. 자동 분석이 쓰는 컬럼 분류를 그대로 재사용해 범주·스윕 노브·연속량·식별자를 가리고, 이름은 "둘 중 어느 쪽이 점수고 어느 쪽이 비용인가"를 고르는 데만 씁니다.
- 덕분에 `zeta`·`kv` 같은 도메인 약어만 있는 데이터에서도 축이 제대로 잡히고, `seed_id` 같은 식별자가 축으로 뽑히지 않습니다.
- 트레이드오프 프리셋의 X축이 스윕 노브 대신 **연속량(지연 등)** 을 먼저 고릅니다 — 노브를 쓰면 스윕 프리셋과 같은 그림이 됩니다.

### v0.17 — 처음 열었을 때 누를 것
- 카드의 `프리셋` 버튼에 **기본 프리셋 5종**이 생겼습니다(평균 비교·스윕 추세·트레이드오프·두 조건 격자·값 분포). 저장한 프리셋이 없어도 바로 시작할 수 있습니다.
- 컬럼 이름을 박아 두지 않고 **지금 데이터에서 역할을 찾아 맞춥니다** — 범주 컬럼, 값이 몇 개뿐인 스윕 노브, 점수형·비용형 숫자. 역할이 채워지지 않는 항목은 아예 목록에 띄우지 않아, 눌렀더니 빈 차트가 되는 일이 없습니다.

### v0.16.1 — 프리셋과 숨김이 부딪히던 곳
- 숨긴 컬럼을 쓰는 **프리셋을 적용하면 그 컬럼을 다시 표시**합니다. 차트는 그려지는데 축 선택기에서는 그 컬럼을 고를 수 없던 반쪽 상태가 없어집니다. 프리셋에 딸린 계산 컬럼을 복원해 주는 것과 같은 방식입니다.
- 프리셋이 **보조 Y축**에 쓰는 계산 컬럼을 함께 담지 않던 문제를 고쳤습니다(받는 쪽에서 그 축이 비었습니다).
- 프리셋 적용 시 곁들여 한 일(계산 컬럼 복원·숨김 해제)이 **적용 안내에 함께** 표시됩니다. 이전에는 토스트가 곧바로 덮여 보이지 않았습니다.

### v0.16 — 컬럼이 많아도 견디게
**컬럼 숨김**
- 표의 `컬럼 n/m` 버튼에서 체크를 끄면 그 컬럼이 **표·축 선택·필터·자동 분석에서 한꺼번에** 빠집니다. 컬럼이 20~40개인 로그에서 축 하나 고르려고 드롭다운을 훑던 일이 없어집니다.
- **숨김은 삭제가 아닙니다.** 데이터 행은 그대로이고 참조도 끊지 않으므로, 숨긴 컬럼으로 이미 그린 차트는 계속 그려집니다. 목록에는 어디에 쓰이는 컬럼인지(`차트 1`, 계산 컬럼 이름) 함께 표시됩니다.
- 데이터에서 컬럼을 **지우는** 기능은 넣지 않았습니다. 행을 알아보는 기준이 조건 컬럼의 조합이라, 컬럼을 지우면 제외 표시·포인트 레이블·텍스트 마커 앵커가 전부 어긋납니다. 원본은 파일에 있으니 다시 불러오면 됩니다.

**표와 화면**
- 숫자 컬럼을 우측 정렬해 자릿수가 맞습니다(`150`과 `23412.3`).
- 헤더의 내보내기 4종을 `내보내기 ▾` 메뉴 하나로 접었습니다.
- 데이터가 들어오면 파일 드롭 영역이 한 줄로 물러납니다.
- 계산 컬럼을 **보조 축**으로 쓸 때 삭제 사용처에 잡히지 않던 문제를 함께 고쳤습니다.

### v0.15 — 주석이 데이터를 따라갑니다
**텍스트 마커가 점에 묶입니다**
- 마커를 만들 때 클릭한 **점의 정체성**(method·tokens 같은 조건 컬럼 조합)을 함께 저장하고, 그릴 때마다 그 행의 현재 값을 다시 읽습니다. 데이터를 갱신해 값이 바뀌어도 주석이 같은 점을 계속 가리킵니다. 이전 세션의 마커는 지금까지처럼 좌표로 그려집니다.

**어긋나면 조용히 두지 않습니다**
- 앵커 행이 사라지거나(필터·제외·데이터 교체) 축 컬럼이 바뀌어 좌표가 무의미해지면 **그리지 않고** 토스트로 알립니다. 어긋난 주석은 그대로 보고서로 나가기 때문에, 틀린 자리에 남는 것보다 사라지는 편이 낫습니다.
- 설정 → 포인트 레이블 목록에 ⚠와 사유(`축이 바뀜` / `점이 없음`)가 남고, `다시 지정`을 누른 뒤 점을 클릭하면 새 점에 붙습니다.

**데이터와 무관한 메모**
- `＋ 고정 메모`로 차트 영역에 붙는 메모를 답니다(`n=24 · 2026-07 측정`, 측정 조건, 출처 등). 어떤 데이터가 들어와도, 축을 바꿔도 자리를 지키고 드래그로 옮길 수 있습니다.

### v0.14 — 갱신·분포·보조축·정리
**데이터를 다시 넣어도 손으로 한 작업이 남습니다**
- 같은 파일을 갱신해 넣으면 **제외·흐리게 표시와 레이블 위치를 그대로 이어받습니다**. 값이 바뀌어도 조건(method·tokens 같은 컬럼 조합)이 같으면 같은 행으로 봅니다. 이전에는 매주 다시 표시해야 했습니다.

**새 차트·축**
- **히스토그램 · 박스플롯**: 반복 측정의 흩어짐을 보는 용도. 그룹을 지정하면 그룹별 분포를 겹쳐 그립니다.
- **보조 Y축(오른쪽)**: 스케일이 다른 두 지표(예: accuracy와 latency)를 한 그림에. 점선·× 마커로 구분됩니다.
- **축 눈금 표기**: 퍼센트·천단위·지수·소수 자릿수 선택.
- **추세선 적합도**: R²·기울기·n을 차트 구석에 표시(설정 → 고급에서 끌 수 있음).

**범례 수정**
- **모양 그룹만 지정해도 시리즈가 나뉩니다.** 이전에는 그룹(색상)이 비어 있으면 모양 그룹을 통째로 무시해 시리즈가 하나로 합쳐지고 범례도 뜨지 않았습니다.
- **범례는 `숨김`으로 설정할 때만 사라집니다.** 시리즈가 하나뿐이어도 표시되며, 이때 범례에는 그리고 있는 컬럼 이름이 나옵니다.
- 보조 Y축만 있는 차트, 히스토그램·박스플롯도 범례 위치·숨김 설정을 그대로 따릅니다.

**테마 · 화면 정리**
- **차트 색 팔레트를 고를 수 있습니다** (상단 선택). 기본은 지금까지 쓰던 색이고, `Carbon`(IBM 디자인 시스템)·`Okabe-Ito`(색약 안전 학술 표준)·`잉크 톤`(인쇄 지향)을 추가했습니다. 선택은 저장되고 세션에도 함께 담깁니다.
- **다크 모드 색을 교정했습니다.** 기존 다크 팔레트는 어두운 배경 대비 색이 너무 밝아(명도 0.68~0.81) 기준을 벗어나 있었습니다. 색상은 유지하고 밝기·채도만 대역 안으로 옮겼습니다.
- 네 팔레트 모두 **명도 대역 · 채도 하한 · 색약(적록/청황) 인접 분리 · 정상 시야 분리 · 배경 대비**를 라이트/다크 각각에 대해 통과합니다.
- **그래프 면 색**: 설정 → 축 → 그래프 면(`없음`/`아주 옅게`/`옅게`). 면에 색을 깔면 **격자가 흰색으로 빠져** 데이터 뒤로 물러납니다(ggplot·Economist 방식). 팔레트마다 어울리는 톤을 쓰고 다크 모드에서는 반대로 카드보다 살짝 밝게 그립니다. 기본은 `없음` — 논문 그림은 대개 흰 면이 낫습니다.
- 화면 정리: 헤더 버튼을 **주 동작 / 내보내기 / 보기** 세 묶음으로, 글자 크기를 4단계로, 여백을 4px 배수로, 컨트롤 높이·모서리를 하나로 통일했습니다. 카드에 옅은 그림자를 넣어 차트가 종이 위에 놓인 느낌을 주고, 데이터가 없을 때는 안내 문구와 함께 `예시 데이터 불러오기`가 눈에 띄게 배치됩니다.
- 보조 Y축을 켜면 **주의 문구**가 함께 표시됩니다 — 두 축은 눈금을 어떻게 잡느냐에 따라 없는 상관도 있어 보이게 만들 수 있습니다.

### v0.13 — 속도
큰 데이터에서 느려지던 지점을 실측해 고쳤습니다 (2만 행 기준).
- **크기 컬럼을 쓴 차트: 49.5초 → 0.43초.** 점마다 전체 행을 다시 훑던 계산을 렌더당 한 번으로 바꿨습니다(5만 행에서는 사실상 그려지지 않았습니다).
- **설정 패널 열기: 57ms → 2ms.** 컬럼 목록·숫자 판정·고유값을 데이터가 바뀔 때만 다시 계산합니다.
- **WebGL 자동 전환**: 점이 5천 개를 넘으면 자동으로 WebGL로 그립니다(3만 점 산점도 렌더 949ms → 18ms). 설정 → 스타일 → 렌더링에서 `고품질 (SVG)`로 고정할 수 있고, **SVG 내보내기는 자동으로 벡터로 되돌려 저장**하므로 논문용 그림 품질은 그대로입니다.

### v0.12 — 사용성 · 보고서 · 계산 컬럼

**사용성**
- **상태 보존**: 차트를 추가하거나 언어를 바꿔도 **확대(줌)와 설정 패널 접힘 상태가 유지**됩니다. 이전에는 모든 카드를 다시 그려 전부 초기화됐습니다.
- **차트 삭제 되돌리기**: 삭제 후 토스트의 `실행 취소`로 축·색·베이스라인까지 그대로 복원됩니다.
- **카드 순서·접기**: 카드 헤더의 `↑`·`↓`로 순서 변경, `▾`로 그래프만 접어 목록처럼 훑기.
- **필터를 다른 차트에도**: 설정 → 필터의 `이 필터를 다른 차트에도` 버튼으로 한 번에 복사(전체 적용 포함).
- **예시 데이터 버튼**: 데이터가 없을 때 `예시 데이터 불러오기` 한 번으로 바로 체험 — 파일을 더블클릭해 연 경우에도 동작합니다.
- 키보드·접근성: `ESC`로 모달·팝오버 닫기, 붙여넣기 창 자동 포커스, 포커스 표시, 아이콘 버튼 설명, 토스트 스크린리더 알림.

**보고서 연결**
- **차트 캡션**: 설정 → 스타일 → 캡션. 차트 아래에 표시되고 리포트에 함께 나갑니다.
- **`내보내기 ▾` → `리포트 MD`**: 마크다운 리포트(.md)와 차트 PNG를 함께 저장합니다. 리포트에는 차트별 **캡션·차트 설정(유형/축/그룹)·적용된 필터 조건**이 들어가고, 분석을 실행했다면 **인사이트 요약과 해석 고지**까지 포함됩니다.
- **`인사이트 복사`**: 분석 패널에서 발견을 마크다운 목록으로 클립보드에 복사(오프라인 파일에서도 동작).

**계산 컬럼 확장**
- **상수 연산**: 이항 연산의 두 번째 자리에 숫자를 직접 입력 (예: `latency_ms ÷ 1000`, `cost_usd × 1000`). 어떤 단위로 볼지는 데이터와 읽는 사람에 따라 다르니 도구는 어느 쪽도 강요하지 않습니다.
- **정규화**: 0~1 정규화 · 최대값 대비 % · z-score. **전체 또는 그룹별** 기준 선택.
- **순위**: 오름/내림, 전체 또는 그룹별 (예: method 안에서의 순위).
- **구간화**: 동일 폭 N구간 → 문자열 라벨이 되어 그룹·필터로 바로 쓸 수 있습니다.
- **그룹 집계**: 그룹별 평균/합/최소/최대/개수를 각 행에 붙임 (기준 대비 델타와 조합하면 상대값 계산).
- 정의 **수정**(`✎`)과 **계산 순서 변경**(`↑`·`↓`) — 파생 컬럼을 다른 파생 컬럼의 입력으로 쓸 때 순서가 중요합니다.
- **프리셋이 계산 컬럼 정의를 함께 나릅니다**: 파생 컬럼을 축으로 쓰는 프리셋을 받은 사람에게도 그대로 적용됩니다(필요한 정의를 자동 생성).

### v0.11.1 — 분석 정합성 수정
- 표에서 행을 제외하거나 되돌리면 **분석 결과가 즉시 낡음으로 표시**됩니다(이전에는 제외 전 기준 인사이트가 그대로 남았습니다).
- `visualizer.py`로 폴더를 열었을 때 **같은 이름의 파일이 갱신되면 최신 내용으로 다시 읽습니다**(이전에는 건너뛰어 지난 데이터가 남았습니다).
- 자동 저장이 용량 한계로 실패하면 조용히 넘어가지 않고 알려줍니다.
- 데이터셋이 1개로 줄면 `_source`를 참조하던 축·그룹·필터 설정을 정리합니다.
- 분석: **설계값(조건)이 2개 이상이면 그 조합 단위로 짝을 맞춥니다**(이전에는 첫 번째 조건만 사용). 1:1로 대응하는 설계값은 대표 하나로 접고, 그룹 후보 상한을 24로 올려 모델 20종 비교 같은 경우도 다룹니다.
- 분석 패널에 **검사 범위 한 줄**(그룹 후보·설계값·제외된 컬럼과 이유)이 표시돼, 발견이 없을 때 그 이유를 알 수 있습니다.

### v0.11 — 자동 분석 패널
- 상단 **`분석` 버튼**: 컬럼 프로파일(종류·결측·고유값·최소/중앙/최대/평균/표준편차) + 자동 인사이트 + 프로파일 CSV 내보내기.
- 인사이트는 **데이터(무결성) → 주의(교란) → 발견** 3단계: 상수·빈 컬럼, 숫자에 섞인 문자, 중복 행, 그룹 편향 결측, 측정 안 한 조합 /
  심슨 역설(합치면 뒤집히는 관계)·교차(조건에 따라 우열이 바뀜) / 상관·그룹 차이·포화 지점·이상치.
- **거짓 발견 방지가 핵심**: 정의상 같은 컬럼(예: cost=latency×5e-4)은 대표 하나로 접고, 설계 노브끼리의 상관은 스캔하지 않으며,
  합친 상관이 그룹별과 어긋나면 수치 대신 경고를 냅니다. 이상치는 반복 셀 안 또는 국소 추세 잔차에서 MAD로만 판정하고 자동 제외하지 않습니다.
- **p값·"유의" 표현을 쓰지 않습니다** — 원단위 차이 + 조건별 방향 일관성(예: 6개 중 6개 동일 방향) + **부트스트랩 구간(95%)**으로 신뢰도를 표시. 리샘플링 단위는 행이 아니라 **측정 조건(블록)**이며(벤치마크 행은 서로 독립이 아님), 결정적 난수를 써서 같은 데이터면 항상 같은 구간이 나옵니다. 구간이 0을 포함하면 발견으로 내보내지 않습니다.
- 결과는 세션에 저장하지 않고 데이터가 바뀌면 버립니다. 인사이트 문장은 KO/EN 모두 지원.

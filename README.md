# VTC Visualizer

[English](README.en.md) | **한국어**

CSV/JSON 데이터를 브라우저에서 논문·기술문서 스타일의 인터랙티브 그래프로 그리는 범용 시각화 도구입니다.
토큰 버짓 대비 성능, 속도 대비 성능 같은 벤치마크 비교 그래프를 자유롭게 커스텀할 수 있습니다.
모든 데이터는 브라우저 안에서만 처리되며 외부로 전송되지 않습니다.

> 📊 **어떤 차트를 언제, 어떻게 써야 잘 전달될까?** — 차트 선택 기준과 시나리오별 레시피는 **[시각화 가이드 (GUIDE.md)](GUIDE.md)** 를 참고하세요.

## 빠른 시작

세 가지 방법 중 아무거나:

1. **더블클릭** — `index.html`을 브라우저로 열고 파일을 드래그 앤 드랍 (인터넷 필요: 차트 라이브러리를 CDN에서 로드)
2. **완전 오프라인** — `index-offline.html`을 더블클릭 (인터넷 불필요, 파일 하나만 복사해가면 어디서든 동작)
3. **폴더 자동 로드** — 데이터 폴더를 지정해 서버 실행:

   ```bash
   python visualizer.py .                 # 처음이라면: 동봉된 example.csv로 바로 체험
   python visualizer.py results/          # results/ 안의 *.csv, *.json 자동 로드
   python visualizer.py                   # 빈 상태로 시작
   python visualizer.py results/ --port 8765
   python visualizer.py results/ --host 0.0.0.0   # 같은 네트워크의 다른 기기에서 열기(폴더가 공개됩니다)
   ```

   폴더의 파일이 바뀌면 화면의 `폴더 감시`를 켜 두세요 — 새 결과가 자동으로 들어옵니다.

   하위 폴더의 파일까지 함께 읽습니다(목록에는 `sub/run1.csv`처럼 상대 경로로 나옵니다).
   숨김 폴더(`.git`·`.venv` 등)와 폴더 밖을 가리키는 심볼릭 링크는 건너뛰고, 목록은 500개까지입니다.

동봉된 `example.csv`를 드래그해서 기능을 먼저 둘러봐도 좋습니다 — 4개 method × 토큰 버짓(500~16k) 스윕 24행(중복 없음)으로,
토큰이 많을수록 정확도는 포화 곡선으로 오르고 지연·비용은 늘어나는 식의 상식적인 추세가 들어 있습니다
(예: X=tokens, Y=accuracy, 그룹=method — 필터 없이 바로 깔끔한 곡선이 나옵니다).

## 5분이면 첫 그림이 나옵니다

1. `index.html`을 열고 CSV 파일을 창 안에 떨어뜨립니다. 파일이 없다면 `예시`를 누르세요.
2. 데이터 카드에 `이렇게 그려보기:` 줄이 뜹니다. 지금 컬럼으로 실제로 그려지는 것만 나오니 아무거나 눌러 보세요. 첫 차트가 그 자리에서 그려집니다.
3. 마음에 안 들면 안내 줄의 `실행 취소`를 누르고 다른 것을 고릅니다.
4. 차트 카드의 `⚙ 설정`을 열어 X축·Y축·그룹을 바꿉니다. 자주 쓰는 열여섯 줄만 먼저 보이고, 나머지는 `고급 설정 … 더 보기`에 있습니다.
5. 다 되었으면 카드의 `PNG` 또는 `SVG`. 논문 규격이 정해져 있다면 설정 → 내보내기 규격에서 `논문 2단 (170mm)` 같은 프리셋을 고르세요.

그다음에 무엇을 할지는 [시각화 가이드](GUIDE.md)의 레시피를 보세요. "어느 method가 가장 좋은가", "토큰을 늘리면 어디서 포화되는가" 같은 질문별로 설정이 적혀 있습니다.

## 데이터 입력 방법

- CSV/JSON 파일 **드래그 앤 드랍** (여러 개 동시 가능)
- **파일 열기… / 폴더 열기…** 버튼
- **붙여넣기** — 페이지 어디서나 ⌘/Ctrl+V, 또는 **직접 입력…** 버튼. 넣기 전에 몇 행 × 몇 컬럼인지, 구분자를 무엇으로 읽었는지 보여 줍니다
- `visualizer.py`로 실행한 경우 지정 폴더의 파일 자동 로드

파일을 계속 추가하면 데이터가 누적 병합됩니다. 같은 파일명을 다시 넣으면 교체됩니다.

## 데이터 포맷 (입력 계약)

- **CSV**: 첫 줄이 헤더, 이후 한 행 = 한 측정점. 구분자는 **쉼표 · 탭 · 세미콜론 · 파이프**를 자동으로 알아냅니다(헤더와 본문의 열 수가 맞는 것을 고릅니다).
- **JSON**: 객체 배열 `[{"method": "ours", "tokens": 4000, "score": 0.744}, …]`
- **필수 컬럼은 없습니다.** 숫자 컬럼은 자동으로 축 후보가 되고, 문자열 컬럼은 그룹(색상)·필터 후보가 됩니다.
- 컬럼 이름은 자유이며, 파일마다 컬럼이 달라도 됩니다(합집합으로 병합, 빈 값은 `–`).
- 파일을 2개 이상 로드하면 출처 파일명이 `_source` 컬럼으로 나타나 그룹·필터에 쓸 수 있습니다 (1개일 땐 숨겨짐).

**숫자를 읽는 규칙** — 추측은 셀이 아니라 **컬럼 단위**로 합니다. 데이터셋 칩의 `ⓘ`를 누르면 그 파일을 어떻게 읽었는지 볼 수 있습니다.

| 입력 | 어떻게 읽나 |
|---|---|
| `1,234.5` / `1.234,5` | 컬럼 전체가 한 형식이면 그 형식으로(미국식/유럽식). 섞여 있으면 바꾸지 않고 문자열로 둡니다 — 한쪽을 고르면 반드시 절반이 틀립니다 |
| `N/A` · `NaN` · `-` · `null` · `inf` | 그 컬럼의 나머지가 숫자일 때만 결측으로 봅니다(문자열 컬럼의 `-`는 진짜 값일 수 있습니다) |
| `007` · 16자리 이상 정수 | 문자열로 둡니다 — 숫자로 바꾸면 선행 0과 끝자리를 되돌릴 수 없습니다 |
| `2024-01-05` | 문자열(카테고리)입니다. 시간 축은 아직 없습니다 |
| 중복·빈 헤더 | 버리지 않고 `이름 (2)` · `column 3`으로 바꿔 읽습니다 |
| 필드 중간의 `"` | 글자로 봅니다. 필드 첫 글자의 `"`만 감싸기로 봅니다(RFC4180) |
| `_`로 시작하는 컬럼(`_id`) | 이름을 바꿔 읽습니다(`id`, 이미 있으면 `id_2`). `_`는 도구의 내부 표식(`_source`·`_excluded`·`_muted`)과 같은 자리라 그대로 두면 화면에서 사라지고, 하필 `_excluded`면 그 행이 그래프에서 빠집니다 |
| 계산 컬럼과 같은 이름의 컬럼 | 파일이 이깁니다 — 계산 컬럼 쪽 이름을 `이름 (계산)`으로 바꾸고, 그것을 쓰던 축·필터·다른 계산 컬럼·숨김·주석 앵커를 함께 옮깁니다. 계산 컬럼은 정의만 있으면 다시 만들어지지만 파일의 값은 잃으면 끝이기 때문입니다 |

권장 형태 (long-form / tidy — 한 행에 한 측정점):

```csv
method,tokens,latency_s,score,dataset
baseline,1000,1.2,0.612,MMLU
baseline,4000,3.8,0.681,MMLU
ours,1000,1.4,0.641,MMLU
ours,4000,4.1,0.744,MMLU
```

## 주요 기능

### 데이터 넣기·고르기

| 기능 | 사용법 |
|---|---|
| **데이터 카드 접기** | 데이터 입력 헤더의 `▾`: 파일을 다 넣은 뒤 카드를 헤더 한 줄로 접습니다(245 → 52px). 접혀도 파일을 끌어다 놓을 수 있고, 무엇이 들어 있는지는 한 줄 요약으로 계속 보입니다 |
| **붙여넣기 미리 보기** | 페이지 어디서나 ⌘/Ctrl+V로 상자가 열립니다(입력칸 안에서는 가로채지 않습니다). `추가`를 누르기 전에 `24행 × 5컬럼 — method, tokens, …`와 세미콜론·유럽식 소수 같은 읽기 결과를 보여 주고, 같은 이름이면 갱신된다고 알려 줍니다. 읽지 못하면 그 자리에서 말하고 붙여넣은 내용을 지우지 않습니다 |
| **레시피 칩** | 데이터를 넣으면 데이터 카드에 `이렇게 그려보기:` 줄이 뜹니다 — 지금 컬럼으로 실제 그려지는 레시피만 나오고, 누르면 첫 차트에 적용됩니다(카드는 늘지 않습니다) |
| **예시 데이터** | `예시 데이터 불러오기`로 기본 24행을, `예시 더`로 짝 데이터 5개(메타·가로 CSV·표준편차·seed 반복·자릿수가 다른 두 백엔드)를 넣습니다 — 가이드 레시피 ⑮⑯⑰⑱⑲를 그대로 따라 할 수 있습니다 |
| **가로 → 세로 녹이기** | 데이터 칩의 `⇲` 버튼: 컬럼이 가로로 펼쳐진 파일(`baseline, ours, ablation`)을 한 행 = 한 측정점으로 바꿔 새 데이터셋으로 만듭니다. 원본은 그대로 두고, 녹인 이름 컬럼은 바로 그룹·분할·필터로 쓰입니다 |
| **폴더 감시** | `visualizer.py`로 실행했을 때 나타나는 `폴더 감시` 체크: 폴더의 파일이 바뀌면 자동으로 다시 읽습니다. 실험을 돌리는 중에 열어 두세요 — 제외·흐리게 표시는 그대로 유지되고, 파일이 잠깐 사라져도 화면에서 지우지 않습니다 |
| **파일 간 결합** | 계산 컬럼 → 종류 `다른 파일에서 가져오기`: 다른 파일의 값을 키로 찾아 컬럼 하나로 붙입니다 (예: `example.csv`에 `methods.csv`의 `params_b`). 키 후보는 양쪽에 다 있는 컬럼만 나오고, 고르는 즉시 몇 행이 짝을 찾는지 미리 알려 줍니다. 짝이 여럿이면 첫 값/평균/합/최소/최대/개수로 접습니다. 행은 절대 늘어나지 않습니다 |
| **계산 컬럼** | 데이터 입력 아래 "계산 컬럼": 기존 컬럼으로 새 컬럼 계산 — 이항 연산(A−B, A/B 등) 또는 기준 대비 델타·유지율(예: dense 대비). 원본 파일 불변, 축·필터로 바로 사용 |
| **라벨 조합 컬럼** | 계산 컬럼 → 종류 `라벨 조합`: 값을 계산하지 않고 여러 컬럼의 값을 이어 붙여 문자열 컬럼을 만듭니다. 조각마다 앞뒤 텍스트를, 사이에는 구분자를 붙일 수 있습니다 (예: `method` + `frames` → `baseline · 8frm`). 만들어진 컬럼은 그룹·분할·필터·막대 X축으로 바로 쓰입니다 |
| **컬럼 숨김** | 표의 `컬럼 n/m` 버튼: 체크를 끄면 표·축 선택·필터·자동 분석에서 한꺼번에 빠집니다. 데이터는 그대로이고 이미 그린 차트도 유지됩니다(참조를 끊지 않음). 컬럼이 20~40개인 로그에서 필요한 것만 남길 때 — `쓰는 것만`으로 차트가 참조하는 컬럼만 남기고 `모두 표시`로 되돌립니다 |
| 원본 데이터 | 하단 표: 검색, 컬럼 클릭 정렬(헤더에서 Enter로도), 데이터셋별 삭제, 행 앞 체크박스 해제로 그래프에서 제외, `흐리게` 열로 강조 제외. 숫자 컬럼은 자릿수를 맞춰 우측 정렬 |
| **차트별 데이터** | 파일을 2개 이상 넣으면 각 차트 설정 맨 위에 `데이터` 드롭다운이 생깁니다. 파일을 고르면 그 파일 행만 그리고, 축·그룹·필터 목록도 그 파일에 있는 컬럼만 보여줍니다. 차트마다 다른 파일을 지정할 수 있어 서로 다른 데이터셋을 나란히 놓고 볼 수 있습니다 (`(전체)`로 되돌리면 다시 합쳐서 봅니다) |
| 필터 | 컬럼 조건으로 행을 거릅니다 — 연산자(=·≠·비교·범위·다중 선택·포함)와 방식 4종(조건 밖/맞는 것 × 제거/흐리게), 필터가 여럿이면 결합(모두 만족 AND / 하나라도 OR)을 정합니다. 숫자 범위는 양쪽 손잡이 슬라이더로도 조절합니다. **표의 값을 클릭해도 만들어집니다** — 대상은 도크가 보고 있는 차트입니다 |
| 필터 복사 | 설정 → 필터 → `이 필터를 다른 차트에도` — 같은 조건을 여러 차트에 한 번에 |
| **포인트 제외** | 포인트 클릭 → "이 포인트 제외" → 모든 차트에서 제거. 토스트의 `실행 취소`, 표의 체크박스, `제외 N행 모두 복원` 버튼으로 롤백 |
| **강조/흐리게** | 포인트 클릭 → "흐리게(강조 안 함)" → 제외하지 않고 옅은 회색 배경으로 물러남(focus+context). 강조할 포인트·라인만 살림. 토스트·표에서 복원. 스타일 → `흐리게 색`으로 회색 대신 시리즈 색을 옅게 남길 수도 있음 |
| **자동 분석** | 상단 `분석` 버튼 → 컬럼 프로파일(타입·결측·분위수)과 인사이트를 데이터 문제 → 해석 주의 → 발견 순으로. 등급마다 어떻게 검증하는지 한 줄 안내가 붙고, 각 항목의 `＋ 차트`(같은 설정의 차트가 이미 있으면 `차트 보기`)로 근거 차트로 이동. 발견에는 그 차트 설정(유형·X·Y·그룹)이 함께 표시돼 차트와 대조하기 쉽습니다. 자명한 중복 컬럼·심슨 역설·교차를 걸러내며, p값 대신 원단위 차이와 조건별 방향 일관성을 보여줌 |

### 그리기

| 기능 | 사용법 |
|---|---|
| 차트 추가/복제/삭제 | 상단 `＋ 차트 추가`, 카드의 `복제`/`삭제`(토스트에서 되돌리기) — 한 페이지에 여러 그래프 |
| **차트 유형** | 산점도 · 선 · 산점도+선 · 막대 · 히트맵(2D 격자를 색으로) · 덤벨(카테고리별 짝 비교) · 히스토그램 · 박스플롯(분포) · 바이올린(분포 모양까지) · 누적분포 ECDF(몇 %가 이 값 이하인가) · 축 끊기(값이 두 무리로 갈릴 때 사이를 접어 둘 다 읽히게 — 축 값은 진짜 값 그대로) · 산점도 행렬(고른 지표들의 모든 쌍을 격자로 — 어디에 트레이드오프가 있는지 한 장에서). **선 계열은 X 오름차순으로 잇습니다**(파일 순서가 아니라). 문자열은 자연 정렬이라 `v2 → v9 → v10 → v100`으로 갑니다. 같은 X에 점이 여럿이면 파일 순서대로 지나 세로로 오가므로, 그럴 때는 설정이 집계를 켜라고 알려 줍니다 |
| 축·스케일 | 설정 → 축: 레이블, linear/log 토글, min/max 범위(한쪽만 입력해도 됨), **축 뒤집기**(순위처럼 작을수록 위여야 하는 값), 그리드 |
| **축 눈금 표기** | 설정 → 축 → X/Y 눈금 표기: 자동 · 퍼센트 · 천단위 · 지수 · 소수 자릿수(0~3) · **정수 1칸씩**(순위축이 `1 1 2 2`로 겹쳐 보이지 않게) |
| **보조 Y축** | 설정 → 데이터 → 보조 Y축: 스케일이 다른 두 지표를 한 차트에 (오른쪽 축, 점선·× 마커) |
| **집계** | 설정 → 데이터 → 집계: 같은 X(히트맵은 같은 칸)의 여러 행을 평균·중앙값·합계 등으로 한 점/한 칸으로 요약합니다. 유형이 달라도 자리는 하나입니다 |
| **오차** | 설정 → 데이터 → 오차: `없음 / <컬럼> / 표준편차 / 표준오차`. `score_std`처럼 ± 값이 이미 컬럼으로 있으면 그대로 그리고, 집계가 평균이면 σ·SE를 고를 수 있습니다(중앙값·최소·최대 둘레의 σ는 그 점의 산포가 아니라 뜻이 없습니다). 집계 중에는 컬럼 쪽을 무시합니다. 밴드(±kσ)는 설정 → 고급 |
| **바 차트** | 유형 → 막대: 나란히/쌓기/**쌓기 100%**(구성비 — 값 표시도 비율로 바뀌고 축에 `(%)`가 붙습니다), 세로/가로, 같은 X의 여러 행 집계(평균·합계·중앙값·최소·최대·개수), 평균 집계 시 오차 막대(±표준편차/±표준오차), 막대 끝 값 표시, 이름/값순 정렬, 불투명도, 숫자 X를 카테고리로 취급(등간격) — 설정 → 막대 옵션(집계·오차는 데이터 묶음). 예: X=method, Y=accuracy, 집계=평균 |
| **작은 다중 차트(facet)** | 설정 → 데이터 → 분할: 컬럼 값마다 작은 차트로 나눠 격자 배치 (복제+필터 없이 small multiples) |
| **모양 그룹 (3번째 차원)** | 설정 → 데이터 → 모양 그룹: 색=그룹1, 마커 모양=그룹2 이중 인코딩. 예: 색=method, 모양=frames → method별 색은 유지하면서 frames별 경향을 모양으로 구분 |
| **연속 색상** | 설정 → 데이터 → 연속 색상: 숫자 컬럼 값을 색 그라데이션(컬러바)으로 — 그룹 색과 상호배타, 산점/선 전용 |
| **추세선** | 설정 → 고급: 선형·2차 다항·로그·지수·거듭제곱·이동평균 피팅을 시리즈별로 표시 (선 종류·굵기 조절), 오차 밴드(±1σ/±2σ) 음영 표시 가능 |
| Pareto frontier | 설정 → 고급: 방향(예: X작을수록·Y클수록 좋음) 선택 |
| **최적점 표시** | 설정 → 포인트 레이블 → 최적점 표시: Y가 가장 큰/작은 점에 라벨을 자동으로 붙입니다(전체 하나 또는 시리즈마다). 그릴 때마다 지금 데이터에서 다시 고르므로 데이터가 바뀌면 따라 움직입니다 — 손으로 놓는 텍스트 마커와 다른 점입니다 |
| **누적 영역** | 설정 → 스타일 → 영역 채우기 → `쌓기`: 시리즈를 위로 쌓아 합계와 구성비를 함께 봅니다(선이 있는 유형 전용) |
| **영역 채우기** | 설정 → 스타일 → 영역 채우기: 선 아래를 시리즈 색의 연한 파스텔톤으로 채움. 시리즈마다 따로도 고를 수 있습니다(시리즈 줄의 채우기 선택 — 빈 값이면 차트 설정을 따름) |
| 선 스무딩 | 설정 → 스타일 → 선 종류: 직선/곡선(spline), 실선/파선/점선 |
| 시리즈 스타일 | 설정 → 스타일: 시리즈별 색·범례 이름 수정·마커 심볼/크기·선 종류(실선/파선/점선)·선 굵기·표시 모드(점만/선만/점+선), 폰트. 순서 바꾸기(↑↓ — 범례·그리는 순서만 바뀌고 색은 그 시리즈를 따라갑니다) |

### 읽기 쉽게 (화면·조작)

| 기능 | 사용법 |
|---|---|
| **차트 색 팔레트** | 상단 선택: 기본 · Carbon · Okabe-Ito · 잉크 톤 — 전부 색약 안전 검증을 통과한 조합, 라이트/다크 각각 별도 단계 |
| **다크 모드** | 우상단 🌙/☀️ 버튼으로 라이트↔다크 전환. 처음엔 OS 설정을 따름, 이후 선택 저장. 차트도 테마에 맞게 조정 |
| 범례 위치 | 설정 → 스타일 → 범례: **그림 밖 아홉 자리**(오른쪽 × 위/가운데/아래, 위·아래 × 왼쪽/가운데/오른쪽) · 그림 안 네 모서리 · 숨김. 위·아래 자리는 제목·축 제목과 겹치지 않게 여백을 스스로 법니다 |
| **설정 도크** | 카드의 `⚙ 설정`을 누르면 **페이지 왼쪽 도크**에서 그 차트의 설정이 열립니다(화면 높이 전체를 씁니다). 한 번에 한 차트만 편집하고, 지금 고치는 차트는 도크 제목과 카드 테두리 두 곳에 표시됩니다. 같은 버튼으로 닫고, 다른 카드의 버튼을 누르면 대상이 바뀝니다. 닫아 둔 상태와 마지막 차트는 브라우저에 남고, 좁은 화면에서는 겹쳐 뜬 뒤 Escape·바깥 클릭으로 닫힙니다 |
| **차트 크기·배치** | 설정 → 스타일 → 차트 크기: 높이 슬라이더 + 폭 네 가지(전체 · 3분의 2 · 절반 · 3분의 1 — 3분의 1이면 세 장이 한 줄에 섭니다. 고른 폭은 이웃 수와 무관하게 그대로 유지됩니다). 상단의 폭 드롭다운(기본/넓게/최대)으로 페이지 전체 폭 조절. 도크 폭(좁게/기본/넓게/아주 넓게)은 패널 위에서 고릅니다. 도크 높이는 화면을 따르고 `하나씩` 체크로 한 묶음만 펼침(시리즈 목록은 접힌 채 시작) |
| 카드 순서·접기 | 카드 헤더의 `↑`·`↓`로 순서를 바꾸고 `▾`로 접습니다. 접힘은 세션에 남아 새로고침해도 유지되고, 헤더의 `모두 접기`로 한 번에 접을 수 있습니다. 확대와 도크 상태는 차트를 더하거나 언어를 바꿔도 그대로입니다 |
| **카드 요약** | 설정을 접으면 헤더에 `유형 · X × Y · 그룹 · 필터 수 · 데이터`가 한 줄로 나옵니다 |
| **간단 ⇄ 전부** | 설정 패널 위 `간단히` 체크(기본 켜짐): 자주 쓰는 16줄만 보이고 나머지는 접힙니다(전부 46줄). 값이 들어 있는 설정은 감추지 않고, 패널 맨 아래 `고급 설정 N줄 더 보기`로 언제든 폅니다 |
| **설정 검색** | 설정 패널 위 검색창에 옵션 이름을 입력하면 해당 항목만 표시. 감춘 고급 설정도 검색으로 찾습니다 |
| **그래프 조작** | 드래그=영역 확대 · 휠=줌 · 더블클릭=전체 보기 · 팬은 모드바 십자 화살표 · `보기 초기화` 버튼으로 리셋. 줌 상태는 스타일을 바꿔도 유지됨 |
| **렌더링 속도** | 설정 → 스타일 → 렌더링: `자동`(5천 점 이상이면 WebGL) / `고품질 (SVG)` / `고속 (WebGL)`. WebGL로 그려도 SVG 내보내기는 벡터로 저장 |
| **언어 (KO/EN)** | 우상단 토글 버튼으로 한국어 ↔ English 전환 (선택 저장됨) |
| **카드 단축키** | 카드 안에 포커스가 있을 때 `Alt+↑`/`Alt+↓` 순서 이동, `Alt+←`/`Alt+→` 접기/펴기. 화살표만 쓰므로 입력칸의 글자 키와 충돌하지 않습니다 |
| **키보드·접근성** | 마우스 없이도 씁니다: 첫 Tab에 차트로 건너뛰기 링크, 설정 컨트롤마다 이름 연결, 팝오버·모달은 열면 포커스가 안으로·Escape면 열었던 버튼으로 복귀(모달은 Tab이 밖으로 새지 않음), 표 헤더는 Enter로 정렬. 포인트 클릭 전용이던 흐리게는 표에서, 베이스라인은 설정 패널에서 값으로 추가합니다 |

### 기준선·주석

| 기능 | 사용법 |
|---|---|
| **베이스라인** | 포인트 클릭 → 메뉴에서 "베이스라인 추가" → 가로/세로 점선. 여러 개 지정 가능, 각각 십자/가로선만/세로선만 선택(추가 폼에서 방향을 먼저 고르면 안 쓰는 칸이 잠깁니다), 이름을 붙여 그림에 표시, 음영은 십자면 사분면·가로선이면 위/아래·세로선이면 좌/우, 음영 색도 지정(비우면 자동), 설정 패널에서 개별 삭제, 그 점(행)에 묶여 데이터를 갱신해도 새 값을 따라갑니다(설정에서 값으로 넣은 기준선은 그 값에 고정). 기준 점이 사라지면 엉뚱한 자리에 그리지 않고 ⚠로 알린 뒤 `다시 지정`할 수 있습니다 |
| **구간 음영** | 설정 → 베이스라인 → `＋ 구간`: 한 축의 범위를 띠로 칠하고 이름·색을 붙입니다(권장 대역, 메모리 초과 구간 등). 베이스라인이 "선 하나"라면 이건 "이 범위" |
| **텍스트 마커** | 포인트 클릭 → "텍스트 마커 추가" → 화살표 달린 주석. 드래그로 이동, 클릭으로 수정/삭제. 마커는 그 점(행)에 묶여서 데이터를 갱신해도 새 값을 따라갑니다. 설정 → 포인트 레이블의 `＋ 텍스트 마커`로 행을 골라서도 만들 수 있습니다(마우스 없이) |
| **고정 메모** | 설정 → 포인트 레이블 → `＋ 고정 메모`: 데이터 점과 무관하게 차트 한구석에 붙는 메모(`n=24 · 2026-07 측정` 등). 데이터·축이 바뀌어도 자리를 지키며 드래그로 옮깁니다 |
| **기준 잃은 마커 알림** | 앵커 행이 사라지거나(필터·제외·삭제) 축 컬럼이 바뀌면 엉뚱한 자리에 그리지 않고 숨긴 뒤 알립니다. 설정 목록에 ⚠와 사유가 남고 `다시 지정`으로 다른 점에 붙일 수 있습니다 |
| 포인트 레이블 | 설정 → 포인트 레이블: 표시 후 드래그로 위치 조정, 클릭으로 개별 숨김. 중복 값은 하나만 표시되고 겹침은 자동 회피 |
| 텍스트 마커 스타일 | 포인트 레이블 그룹에서 전체 글자 크기/색/배경/화살표 설정, 마커 클릭 팝업에서 개별 색·크기 오버라이드 |
| **이미지 주석** | `내보내기 ▾` → `이미지 주석…`: 별도 페이지(`annotate.html`)에서 캡처에 텍스트·화살표·사각형·가리기를 얹고 PNG로 저장합니다. 스크린샷은 붙여넣기(⌘/Ctrl+V)로 바로 넣습니다. 이미지는 브라우저 밖으로 나가지 않습니다. 별도 파일이므로 `index.html`과 같은 폴더에 두어야 합니다 |

### 내보내기·이어 쓰기

| 기능 | 사용법 |
|---|---|
| **여러 그림 한 판으로** | `내보내기 ▾` → `여러 그림 한 판으로…`: 고른 차트를 격자(1~4열)로 조판해 PNG 한 장으로. 칸 이름 `(a) (b) (c)`, 판 전체 폭을 mm/inch·dpi로 지정. 칸마다 자기 비율을 지키므로 눈금 간격이 왜곡되지 않습니다 |
| 내보내기 | 카드의 `PNG`(3배 해상도) / `SVG` 버튼, 상단 `내보내기 ▾` 메뉴의 `모든 차트 PNG`(전체 한 장), 표의 `CSV 내보내기`(현재 필터된 데이터) |
| **내보내기 규격** | 설정 → 내보내기 규격: 논문 1단(85mm)·2단(170mm)·슬라이드 프리셋 또는 mm/inch로 직접, dpi 지정. 안내에 저장될 픽셀과 본문 글자의 pt가 나옵니다 (dpi를 올려도 글자의 물리 크기는 그대로 — 키우려면 글자 크기를 올립니다). 리포트에 들어가는 그림도 이 규격을 따릅니다 |
| **차트를 표로** | 카드의 `표` 버튼: 그 차트가 쓰는 컬럼만, 그 차트의 필터를 적용한 행으로 표를 함께 보여줍니다. 그래프를 읽을 수 없을 때의 유일한 길이고, 정확한 값을 확인할 때도 씁니다 |
| **공유용 HTML 한 장** | `내보내기 ▾` → `공유용 HTML 한 장`: 지금 데이터와 모든 차트 설정을 한 파일에 박아 저장합니다. 받는 사람은 더블클릭만 하면 됩니다(도구도 세션 파일도 따로 필요 없음). `index-offline.html`에서 만들면 인터넷 없이도 열립니다 |
| 세션 | 자동 저장(localStorage) + `내보내기 ▾` 메뉴의 `세션 내보내기/가져오기`(JSON 파일)로 공유 가능. **행은 IndexedDB에, 차트 설정은 따로 저장하므로 큰 데이터도 새로고침을 넘습니다**(20만 행 확인). 담을 자리가 없을 때에도 차트·계산 컬럼·숨긴 컬럼은 그대로 돌아오고 — 그때는 어떤 파일을 다시 넣어야 하는지 점선 칩으로 알려 줍니다. 서버로 연 폴더의 데이터는 저장하지 않고 다음 실행에서 다시 읽습니다. 저장이 꺼지면 상단에 `저장 꺼짐`이 계속 떠 있습니다(눌러서 파일로 내보냅니다) |
| **기본 프리셋** | 카드의 `프리셋` 버튼 상단: 평균 비교(막대)·스윕 추세(선)·트레이드오프(Pareto)·두 조건 격자(히트맵)·값 분포(박스). 컬럼 이름을 가정하지 않고 지금 데이터에서 역할(범주·스윕 노브·점수·비용)을 찾아 맞춥니다. 종류는 값의 분포로 가리므로 이름이 도메인 약어여도 동작하고, 식별자·시드 컬럼은 축으로 쓰지 않습니다. 맞는 컬럼이 없는 항목은 목록에 뜨지 않습니다 |
| **보기 설정 일괄 적용** | 설정 → 스타일 → `이 보기 설정을 다른 차트에도`: 글꼴·글자 크기/색·범례·크기·그리드·면 색·눈금 표기·내보내기 규격을 한 번에 복사(되돌리기 있음). 축·그룹·필터처럼 데이터를 가리키는 설정은 복사하지 않습니다 |
| **차트 프리셋** | 카드의 `프리셋` 버튼: 현재 차트 설정만(데이터 제외) 이름 붙여 저장 → 같은 컬럼 이름의 새 데이터에 클릭 한 번으로 재적용. JSON `내보내기/가져오기`로 팀 공유 |

### 팁: 어떤 차트를 언제?
차트 선택 기준(추세=선, 크기 비교=막대, 트레이드오프=산점도), 시나리오별 설정 레시피(평균+오차 막대, 스택,
랭킹, Pareto…), 세 번째 차원 보기, 발표용 마무리 팁은 **[시각화 가이드 (GUIDE.md)](GUIDE.md)** 에 정리되어 있습니다.

## 내 데이터를 이 포맷으로 변환하기 (에이전트 요청문)

자기 로그/실험 결과의 포맷이 무엇이든, 아래 요청문을 Claude 등 아무 LLM 에이전트에 복사해서 붙여넣고
자신의 데이터 파일(또는 경로)을 함께 주면 됩니다:

```text
아래 "입력 계약"에 맞는 CSV 또는 JSON 파일로 내 데이터를 변환해줘.

[입력 계약 — VTC Visualizer]
1. CSV(첫 줄 헤더) 또는 JSON 객체 배열. 인코딩 UTF-8.
2. long-form(tidy) 형태: 한 행 = 한 측정점. 반복 측정이면 행을 반복한다.
   (예: method별 × token budget별 점수라면 method,tokens,score 3컬럼으로 행을 나열)
3. 필수 컬럼은 없다. 다만 다음을 지키면 좋다:
   - 비교 대상(방법/모델/설정 이름)은 문자열 컬럼 하나로 (예: method) → 그래프의 색상 그룹이 된다.
   - 축으로 쓸 값(토큰 수, 시간, 점수 등)은 각각 숫자 컬럼으로. 단위는 컬럼명에 명시 (예: latency_s, cost_usd).
   - 조건 구분(데이터셋, GPU 종류 등)도 각각 별도 컬럼으로 → 필터로 쓸 수 있다.
4. 숫자 컬럼에는 숫자만 넣는다 (단위 문자열 금지, 천단위 콤마 금지, 결측은 빈 값).
5. 컬럼명은 영문 소문자+언더스코어 권장. "_source"라는 이름은 예약되어 있으니 쓰지 말 것.

변환 결과는 *.csv 또는 *.json 파일로 저장해줘. 변환 규칙이 애매한 부분은 나에게 물어봐줘.
```

변환이 자주 필요하면 위 계약에 맞는 자기만의 변환 스크립트를 만들어 쓰는 것도 좋습니다.

## 알려진 한계 (일부러 그렇게 둔 것)

고칠 수 있지만 값이 안 나온다고 판단해 그대로 둔 것들입니다. 이유를 적어 두는 편이 다음에 같은 판단을 다시 하는 것보다 낫다고 봅니다.

- **분석 실행이 오래 걸립니다** — 연속량 컬럼이 20개인 5만 행에서 약 3초. 눈에 띄는 부분(상관 쌍마다 그룹을 다시 나누는 것)을 미리 계산해 봤더니 **10%밖에 줄지 않았고**(3,177 → 2,865 ms) 대신 미묘한 순서 불변이 생겨 되돌렸습니다. CPU 프로파일상 비용이 한 곳이 아니라 흩어져 있습니다. 버튼을 눌러 기다리는 동작이고, 스캔은 표본을 쓰므로 행이 늘어도 거의 평평합니다.
- **차트를 여러 장 열면 WebGL 컨텍스트 한도에 걸릴 수 있습니다** — 브라우저 제한입니다. 설정 → 스타일 → 렌더링에서 `고품질 (SVG)`로 고정하면 피할 수 있습니다.
- **기본 프리셋은 데이터당 한 벌만 제안합니다** — 연속량이 여럿이어도 점수·비용을 하나씩만 고릅니다. 후보를 여러 개 내놓으면 목록이 금세 길어집니다. 적용한 뒤 축을 바꾸세요.
- **폴더 감시는 4초 주기 폴링입니다** — 로컬 폴더에서는 충분했습니다.
- **브라우저에 담아 두는 데이터에도 한도는 있습니다** — 행은 IndexedDB에 담기므로 20만 행도 돌아오지만, 디스크가 부족하거나 사생활 모드처럼 IndexedDB를 못 쓰면 localStorage(약 5MB)로 물러섭니다. 그때도 차트 설정은 남고, 데이터는 같은 파일을 다시 넣거나 서버로 폴더를 열어 두면 됩니다. 확실히 보관하려면 `세션 내보내기`를 쓰세요.
- **파일 간 결합은 정의 하나당 컬럼 하나입니다** — 메타를 넷 붙이려면 정의를 넷 만듭니다. 한 정의가 여러 컬럼을 내면 삭제·이름 충돌 검사·사용처 조회가 전제하는 "정의 1 = 이름 1"이 흔들립니다.

- **v0.63** — 축 뒤집기와 정수 눈금(1칸)을 더해 **범프 차트**(순위 변화)를 계산 컬럼 + 선으로 만들 수 있습니다(가이드 레시피 ㉒). 막대에 `쌓기 100%`가 생겨 구성비를 봅니다 — 값 표시도 비율로 바뀝니다.
